# ใบงาน Replit — ผัง 2D ออกใบเสนอราคาจริง + บันทึกแบบไว้ดูซ้ำ
สร้าง 14 ก.ย. 2026 · แอป Knight Basins · repo Knightfurnich/KnightBasins-Source

## เป้าหมาย
จากผัง 2D Studio ที่ลูกค้าวางเอง → กดปุ่มแล้วได้ **ใบเสนอราคาจริง** ที่มีตัวเลขครบ
พร้อม **บันทึกแบบไว้เปิดดูซ้ำได้** (รวมลิงก์ read-only ส่งให้ลูกค้า)

## สิ่งที่ต้องทำ
1. ปุ่ม "ขอใบเสนอราคาจากแบบนี้" ในผัง 2D → สร้าง **ใบเสนอราคา** (ไม่ใช่แค่รายการลูกค้าสนใจ)
   แล้วพาผู้ใช้ไปหน้าใบเสนอราคาที่แสดงรายการครบตามผัง
2. บันทึกแบบลงฐานข้อมูลผูกกับเลขที่ใบเสนอราคา: รูปทรง (I/L/U) · ขนาด · backsplash ·
   สีที่ใช้คำนวณ · รายการอ่าง + ตำแหน่งที่วาง (x,y) · พื้นที่ติดตั้ง
3. เปิดดูซ้ำได้: เปิดลิงก์เดิมแล้วเห็นแบบ+ตำแหน่งอ่างเหมือนเดิมทุกจุด (รีเฟรช/คนละเครื่องก็ได้)
4. ลิงก์ read-only: คนที่ไม่ได้ล็อกอินแอดมินเปิดดูได้ แต่แก้ไม่ได้
5. ตรวจว่าใบเสนอราคาที่พิมพ์/บันทึก PDF แสดงแบบที่บันทึกไว้ถูกต้อง

## กฎราคา (ห้ามคิดใหม่ ห้ามเบี่ยง)
- หิน: พื้นที่ = (กว้าง × ยาว) + backsplash (ถ้าติ๊ก) × เรตรวมติดตั้งของสีที่เลือก (บาท/ตร.ม.)
- **ห้ามหักพื้นที่ช่องเจาะอ่างออกจากพื้นที่หิน** และ **ห้ามบวกค่าขอบ/ค่าเจาะ**
- อ่าง: คิด **จำนวนใบ** × ราคา/ชุด · ค่าติดตั้งอ่าง 5,000 บาท/ชุด · **ฟรีเมื่อสั่งตั้งแต่ 3 ชุด**
- ค่าดำเนินการงานพื้นที่เล็ก: กทม./ปริมณฑล ต่ำกว่า 5 ตร.ม. = 5,000 · ต่างจังหวัด ต่ำกว่า 10 ตร.ม. = 8,000
- เกิน 0.76 × 3.60 ม. = เตือนเรื่องรอยต่อ
- ระยะขอบอ่าง ≥ 50 มม. จากขอบเคาน์เตอร์ + รุ่นที่ไม่ระบุขนาดหลุม ยังคงบล็อกการส่งเหมือนเดิม
- VAT 7% เป็นตัวเลือก (ติ๊ก/ไม่ติ๊ก) ต้องไม่ถูกบังคับเปิดเอง

## เกณฑ์ตรวจรับ (แนบหลักฐานจริงทีละข้อ)
1. กดจากผัง 2D → ได้ใบเสนอราคาที่มีทั้งรายการหินและอ่าง พร้อมเลขที่เอกสาร (แนบภาพ)
2. รีเฟรชหน้า/เปิดลิงก์เดิม → แบบและตำแหน่งอ่างเหมือนเดิมทุกจุด (แนบภาพก่อน-หลัง)
3. เปิดลิงก์ด้วยเบราว์เซอร์ที่ไม่ได้ล็อกอินแอดมิน → ดูได้ แก้ไม่ได้ (แนบภาพ)
4. ตรวจเลข: ตัวอย่างผัง 1.80 × 0.60 ม. **ติ๊ก backsplash** สี 7,500/ตร.ม.
   → พื้นที่หิน 1.26 ตร.ม. = 9,450 · อ่าง 3 ใบ × 19,000 = 57,000 ค่าติดตั้งฟรี
   · ค่าดำเนินการ 5,000 → **รวม 71,450**
   (ถ้า **ไม่ติ๊ก** backsplash: พื้นที่ 1.08 ตร.ม. = 8,100 → รวม 70,100 เป็นเลขของอีกกรณี ห้ามใช้ปนกัน) (แนบภาพ)
5. ใส่ 2 อ่าง → ยังคิดค่าติดตั้ง 5,000/ชุด (ไม่ฟรี) (แนบภาพ)
6. ไม่หักพื้นที่ช่องเจาะ: ใส่/ถอดอ่างแล้วพื้นที่หินต้องเท่าเดิม (แนบภาพ)
