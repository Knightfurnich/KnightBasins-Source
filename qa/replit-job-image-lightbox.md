# ใบงานส่ง Replit — เพิ่มระบบ Image Lightbox / Zoom บนการ์ดสินค้า

> ตามคำสั่งเจ้าของ (13 ก.ย. 2026): กดที่รูปภาพสินค้าแล้วขยายใหญ่ขึ้น (LightBox) ชัดเจน

---

## สิ่งที่ต้องทำ
1. **การคลิกที่รูปสินค้า (Image Viewer / Lightbox):**
   - บนการ์ดสินค้า (ทั้งใน Catalogue และ Catalogue Workbench ในแผงน้องไนท์) เมื่อผู้ใช้กดที่ตัวรูปภาพ (Thumbnail) ให้เปิดป๊อปอัพ (Modal / Lightbox Dialog) แสดงภาพขนาดขยายใหญ่ (High-resolution / Full view)
   - หากสินค้านั้นมีทั้งภาพตัวอย่างสี (`imageUrl` / `swatch`) และภาพแผ่นใหญ่ (`slabImageUrl`) ให้มีแท็บหรือปุ่มสลับดูภาพแผ่นใหญ่ (Slab View) ได้ด้วย
   - มีปุ่มปิด (X) หรือกดพื้นที่ด้านนอกเพื่อปิด Modal กลับมาหน้าเดิม

2. **ไม่กระทบการเลือกสินค้า:**
   - การกดที่ตัวรูปภาพ = **เปิดดูภาพขยายเท่านั้น** (ไม่เป็นการเลือกสินค้านั้นเข้าถาด)
   - การกดปุ่มลูกศร `>` หรือพื้นที่อื่นบนการ์ด = **เลือกสินค้า / ดูรายละเอียด** ตามปกติ

---

## เกณฑ์ตรวจรับ
```
1. กดที่รูปสินค้าบนการ์ด -> มี Modal ป๊อปอัพขึ้นมาแสดงรูปขนาดขยายใหญ่ชัดเจน (แนบภาพ)
2. ถ้ามีรูปแผ่นใหญ่ (Slab) -> สามารถสลับดูรูป Slab ได้ (แนบภาพ)
3. กดปิด Modal หรือกดนอกพื้นที่ -> ปิด Modal กลับมาหน้าเดิมได้ปกติ
```
