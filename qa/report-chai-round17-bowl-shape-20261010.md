## สรุป 5 บรรทัด
1. **เพิ่มอะไร:** `GET /api/catalog` ทุกอ่างมี 3 คีย์ใหม่ `bowlShape` · `bowlShapeLabel` · `bowlOverflowHole` — ค่าจริงเฉพาะ KF003/KF006 ที่เหลือ `null`; เพิ่มเป็นโค้ดฝั่ง API (ไม่มีคอลัมน์ DB ใหม่) และใส่ในสำเนา static ของเว็บให้ตรงกัน
2. **เทสต์:** api-server 1282 / ผ่าน 1277 / ตก 5 (baseline เครื่องนี้ 1275/1270/5 → +7 ใหม่ผ่านหมด ที่ตกเป็นชุดเดิม) · web 1297 / 1243 / ตก 12 / ข้าม 42 (เท่า main ก่อนแก้เป๊ะ; ที่ตก = release notes/llms/prerender เดิม) · เทสต์ใหม่ 7/7 · พิสูจน์สองทาง 5 แบบ
3. **ตรวจไม่ได้:** ผลบน production หลัง deploy (ต้องรอ deploy) · รูปทรงของอีก 28 รุ่น (ไม่ได้ตรวจภาพรายรุ่นในใบนี้ จึงเป็น `null`) · เทียบ baseline Linux ของใบ (เครื่องผมเป็น Windows) · `tsc --noEmit`: api-server มี 4 error เดิม (`speakingRate`/`enabled`) และ web มี 1 error เดิมที่ `src/admin/AdminVoiceSettings.tsx` (`speakingRate`) จาก lib ที่ลิงก์ค้าง — ไม่มี error ในไฟล์ที่แก้
4. **ความเสี่ยง:** ค่าอยู่ในโค้ด 2 ที่ (api + สำเนาเว็บ) เทสต์ parity ล็อกไว้ไม่ให้เพี้ยน · รุ่นอื่นแสดง `null` ถ้าบอยแสดงคำนี้ต้อง **ซ่อนบรรทัดเมื่อเป็น `null`** ไม่งั้นการ์ดอื่นจะมีช่องว่าง · ชื่อใน `support` route (ใช้ `getCatalogData` เดียวกัน) จะได้คีย์เพิ่มเฉย ๆ ไม่กระทบ
5. **ข้อเสนอ:** ให้เดวิดสั่งตรวจภาพอีก 28 รุ่นเพื่อเติมค่า (ทำเป็นรายการแยก ในใบนี้ไม่ได้แก้) · ถ้าต่อไปต้องให้บอสแก้เองผ่านแอดมิน ค่อยย้ายเป็นคอลัมน์ DB ในใบแยก

## 0–2. Baseline และหลักฐานรูปทรง
Baseline (ดึง 11 ต.ค. 69 ราว 00:40 น.): KF003 กับ KF006 มี `colorCode RW316 · 600×800×200 · หลุม 350×500×130 · ฿19,000` เหมือนกันทุกค่า ไม่มีฟิลด์รูปทรงหลุม
```bash
curl -s https://knightbasins.com/api/catalog | python3 -c "import json,sys;d=json.load(sys.stdin);print([{k:b.get(k) for k in ('sku','name','bowlShape')} for b in d['basins'] if b['sku'] in ('KF003','KF006')])"
```
ก่อน: `bowlShape` เป็น `None` ทั้งคู่ (และ `name` ไม่มีในฟีด) · หลัง: ต้องได้ `rounded-rectangle` / `oval` — **ตรวจบน production ไม่ได้จนกว่าจะ deploy**

หลักฐานภาพ (ดูภาพจริงด้วยตา 11 ต.ค. 69):
- KF003: ภาพหลัก HD `https://knightbasins.com/kb/images/basin-hd/KF003.jpg` — หลุมสี่เหลี่ยมมุมมน มีรูระบายที่ก้นหลุมแต่ไม่มีรูน้ำล้นที่ขอบ · แกลเลอรี `…/catalog-mugpw909-bf8dc319….jpg` เป็นหลุมสี่เหลี่ยมมุมมนเหมือนกัน
- KF006: ภาพหลัก HD `https://knightbasins.com/kb/images/basin-hd/KF006.jpg` — หลุมวงรี มีรูน้ำล้นเล็กที่ขอบหลังของหลุม
