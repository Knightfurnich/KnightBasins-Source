# สรุปสถานะระบบ KnightDesign & งานค้างสำหรับ Replit (รอบถัดไป)

> อัปเดตล่าสุด: 13 ก.ย. 2026 (หลัง Deploy งานวิดีโอ 3D อ่างล้างหน้าสำเร็จ 100%)

---

## 1. สิ่งที่เสร็จสมบูรณ์และใช้งานได้จริงบน Production แล้ว (100%)
- **อ่างล้างหน้า 3D 360° (30/30 รุ่น):** ภาพคมชัดสูงจาก PDF + วิดีโอ 3D หมุน 360° แท้จริงทรงนิ่งเป๊ะ สีตรงปก
- **ระบบพิมพ์ใบเสนอราคาทางการ (Quotation):** รูปแบบทางการ พร้อมข้อมูลบริษัทถาวร ล็อกเลขเอกสารและ Snapshot แบบ immutable
- **แผงน้องไนท์ (KnightSupport Panel):** รองรับ Auto-resize พื้นที่ตรงกลาง + แชทแบบ Timeline
- **ภาพแผ่นหินสังเคราะห์ คมชัดสูง (71 สี):** อัปเดตไฟล์ภาพแผ่นหินความละเอียดสูง (1,000-1,600 px) ลงฐานข้อมูลเรียบร้อยแล้ว

---

## 2. สิ่งที่ต้องสั่ง Replit ทำต่อในรอบถัดไป (Next Tasks)

### 📌 งานที่ 1: แนบภาพ Canvas 2D Mockup และวิดีโอ 3D/QR Code ลงในใบเสนอราคา (Visual Quotation Snapshot)
- **ภาพ 2D Preview:** เมื่อออกใบเสนอราคา ให้บันทึกภาพ Canvas 2D (แบบเคาน์เตอร์ + อ่าง) ลงใน Snapshot แล้วนำไปแสดงกล่อง "ภาพจำลองแบบเคาน์เตอร์ 2D" ในใบเสนอราคาฉบับพิมพ์/PDF
- **วิดีโอ 3D & QR Code:** บนหน้าจอแสดงคลิปวิดีโอ 3D 360° ของอ่างล้างหน้า และเมื่อพิมพ์เป็น PDF ให้แนบ **QR Code สำหรับสแกนดูวิดีโอ 3D** ไว้ข้างๆ รายการอ่างล้างหน้า

### 📌 งานที่ 2: ระบบแสดงภาพตัวอย่างสเกลลายหินจริง (Real-Scale Pattern Preview)
- ใน Lightbox ขยายรูปสี (โดยเฉพาะกลุ่มลายหินอ่อน Veined Series เช่น `KZ802`, `MS112`) ให้มีโหมด **Full Slab Scale (0.76 x 3.60 ม.)** พร้อมระบบ Zoom & Pan
- บน Canvas หน้าออกแบบ (`/design`) เมื่อเลือกสีลายสายแร่ ให้ดึงลายแผ่นจริงมาวางตามสเกลความยาวจริงของท็อปเคาน์เตอร์ (ไม่นำภาพชิปเล็กมาต่อวนซ้ำ)

### 📌 งานที่ 3: ฟีเจอร์สนับสนุนทีมขายเพื่อปิดการขาย (Sales Enablement)
- **ปุ่มคัดลอกลิงก์ส่งให้ลูกค้า:** ปุ่ม "คัดลอกลิงก์ส่งให้ลูกค้า" (`button-share-quote`) สำหรับดูใบเสนอราคาแบบ Read-only
- **ปุ่มส่งแบบเข้า LINE:** ปุ่ม "ส่งแบบเข้า LINE" สรุปภาพแบบ 2D + ราคา ส่งเข้าแชต LINE ลูกค้า
- **ค้นหาสีแบบยืดหยุ่น (Smart Search):** มองข้ามเว้นวรรคและตัวพิมพ์เล็ก-ใหญ่ (`SG420`, `SG 420`, `sg420` ค้นเจอผลลัพธ์เดียวกัน)
- **ป้ายยี่ห้อ/ซีรีส์ (Brand Badges):** แสดงป้ายยี่ห้อ/ซีรีส์ (เช่น Lotte Staron, Zen Stone, Navis) บนการ์ดสีใน Catalogue

```
2. Lightbox สีหินอ่อนมีโหมด Full Slab 0.76 x 3.60 ม. พร้อมระบบซูมดูสายแร่ (แนบภาพ)
3. มีปุ่มคัดลอกลิงก์ Read-only ส่งให้ลูกค้าบนหน้า /quote/:id (แนบภาพ)
4. ค้นหาสี "SG420", "SG 420", "sg420" เจอผลลัพธ์ตรงกัน (แนบภาพ)
```
