## GOAL
ทีมขายกดปุ่มเดียวจากหน้า `/quote/:id` แล้วได้ **ใบเสนอราคาที่พร้อมส่งลูกค้า** (พิมพ์ หรือบันทึกเป็น PDF)

## สภาพปัจจุบัน (ตรวจจากซอร์สแล้ว)
- มีหน้า `/quote/:quoteId` (`artifacts/knightdesign-web/src/pages/quote.tsx`) แสดง draft/ใบเสนอราคา
- มี `data-testid="link-edit-design"` (แก้ไขต่อในหน้าออกแบบ) และ `link-quote-support`
- **ยังไม่มี** ปุ่มพิมพ์/ดาวน์โหลด และไม่มี print stylesheet → ทีมขายต้องแคปจอส่งลูกค้า

## ต้องทำ
1. เพิ่มปุ่ม **"พิมพ์ / บันทึกเป็น PDF"** บนหน้า `/quote/:id` (แนะนำ `testid="button-print-quote"`)
   ใช้ `window.print()` + print stylesheet (`@media print`) — ไม่ต้องเพิ่ม dependency ใหม่ในรอบนี้
2. ใบที่พิมพ์ต้องมี
   - หัวบริษัท: `บริษัท ไนท์ เฟอร์นิช จำกัด (KNIGHT FURNICH Co., Ltd)` ตาม KB
     เบอร์โทร `094-496-1949 · 089-762-2209 · 081-735-5053` · `www.knightfurnich.com`
     LINE OA `KnightBot (@789gcnhq)` — **คัดจาก KB เท่านั้น ห้ามแต่งเพิ่ม**
   - เลขที่อ้างอิง (ใช้ quote id หรือ snapshot id) + วันที่
   - **ข้อมูลที่ลูกค้าให้** (เพื่อให้ลูกค้าตรวจ): ขนาด (กว้าง×ยาว), ความลึก, สี (รหัส+ชื่อ), อ่างที่เลือก, การวัด
   - ตารางรายการ: รหัส · รายการ · จำนวน · หน่วย · ราคา/หน่วย · รวม
   - ยอด: subtotal · ค่าดำเนินการติดตั้ง (ถ้ามี) · **VAT 7%** · รวมทั้งสิ้น
   - หมายเหตุท้ายใบ: "ราคานี้ไม่รวม VAT 7%" เฉพาะกรณีที่ตัวเลขยังไม่รวม VAT ตาม snapshot
3. **ตัวเลขในใบต้องมาจาก snapshot ที่บันทึกไว้** (`calculation_snapshots`) — ห้ามคำนวณใหม่ฝั่งเว็บ
4. ถ้า `measurementStatus = estimated` ต้องมีบรรทัดเตือน:
   "ราคานี้อ้างอิงจากขนาดที่ลูกค้าแจ้ง ยังไม่ได้วัดหน้างานจริง ราคาอาจเปลี่ยนแปลงหลังการวัด"
5. สิ่งที่ **ห้าม** ติดไปในใบพิมพ์: เมนู/แถบนำทาง · ปุ่มแก้ไข · ลิงก์ภายใน · ข้อมูลทีมงาน · ชื่อผู้ใช้/อีเมล

## เกณฑ์ตรวจรับ (ต้องแนบหลักฐานจริง)
```
1. กดปุ่ม -> เข้า print preview ได้ (หรือได้ไฟล์ PDF) — แนบภาพ/ไฟล์ที่ได้
2. ในใบพิมพ์: ไม่มีเมนู/ปุ่มแก้ไข · มีหัวบริษัท+เบอร์โทรครบ · มีเลขที่อ้างอิง+วันที่
3. ตารางรายการครบทุกบรรทัด และยอดตรงกับ snapshot
   เคสอ้างอิง: 0.60 x 1.80 SG420 กทม. -> 1.08 ตร.ม. · subtotal 14,180 · VAT 992.6 · รวม 15,172.6
4. เคส estimated -> มีบรรทัดเตือน (และเคส measured -> ไม่มีบรรทัดนั้น)
5. หน้าเว็บปกติ (ไม่พิมพ์) ต้องเหมือนเดิม: ปุ่มแก้ไขต่อ/ปุ่มคุยกับทีมยังอยู่ · ราคาบนจอไม่เปลี่ยน
6. มี testid ให้ตรวจอัตโนมัติ: button-print-quote + ส่วนของใบพิมพ์อย่างน้อย 1 จุด
```

## ⛔ ข้อห้าม
- ห้ามแตะ auth/ล็อกอิน · ห้ามแตะ persona ผู้ช่วย (เสียงหญิง ค่ะ/คะ ชื่อ "น้องไนท์")
- ห้ามแก้สูตรราคา หรือให้ใบพิมพ์ดึงราคาสดจาก API แทน snapshot
- ห้ามแต่งเลขทะเบียนบริษัท/เลขประจำตัวผู้เสียภาษี/ที่อยู่ ถ้าไม่มีใน KB
- ห้ามเพิ่ม dependency ใหม่ (ทำด้วย print CSS) — ถ้าจำเป็นจริงให้ถามก่อน
