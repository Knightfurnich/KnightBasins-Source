# ใบงาน 405-C (ชัย) — **เปิด 5 ก้อน "ค่าคงที่การค้า" ใน `/api/catalog` เพื่อให้ KB/บอทตามแอปได้เสมอ** (บอสเลือกทาง ก)

**วันที่:** 9 ต.ค. 69 · **ออกโดย:** เดวิด · **เจ้าของงาน:** **ชัย** · **ผู้ตรวจรับ:** **บอส**
**ที่มา:** รีวิว 403-Q (Qwen) ข้อ F.4 ชี้ความเสี่ยงด้านเงิน — **ค่าดำเนินการ (5,000/8,000) · ส่วนลดตามจำนวนแผ่น · ของเพิ่ม** อยู่ **นอกขอบเขตซิงก์** เพราะ `/api/catalog` ไม่ส่งก้อนเหล่านี้ออกมา ⇒ ถ้าฝ่ายขายแก้ค่าในแอป **ฟีด/KB/บอทจะคิดราคาจากค่าเก่าต่อไปโดยไม่มีใครรู้**
**บอสชี้ขาด (9 ต.ค. 69):** **"ข้อ 1 เลือก ก"** = **ให้ฝั่งแอปส่งก้อนเหล่านี้ใน API** แล้วให้ระบบซิงก์ตาม (ไม่ใช่ประกาศว่าคงที่)
**กติกา:** read-only ต่อ production (ห้าม POST/DELETE) · ทำงานผ่าน branch + PR · **ห้าม push ตรงเข้า `main`** · ห้ามแก้ราคา/ค่าใด ๆ — งานนี้ **ส่งออกข้อมูลที่มีอยู่แล้ว** เท่านั้น

✅ มาตรฐานการออกใบงาน · 12/12 · 9 ต.ค. 69 · เดวิด

GOAL:
  A. **ให้ `GET /api/catalog` ส่งออก 5 ก้อนนี้** (โครงสร้างต้องตรงกับฟีด เพื่อให้เทียบ 1:1 ได้ — ใช้ค่าที่แอปใช้คิดราคาจริง ไม่ใช่ก็อปจากฟีด):
       (1) `installation` = `{ "rules": [ {scope, condition, charge, unit}, … ], "delivery_window": "<ข้อความ>" }`
             ตัวอย่างค่าปัจจุบัน: กทม.+ปริมณฑล/พื้นที่<5 ตร.ม./5000 บาทต่องาน · ต่างจังหวัด/<10 ตร.ม./8000 · รับเองที่โรงงาน/0 · งานกลางคืน(ตจว.)/5000 บาทต่อคืน · ค่าเดินทาง+เบี้ยเลี้ยง/`null`
       (2) `discount_tiers` = `[ {min, max|null, type: "none"|"per_sheet"|"percent", amount, note}, … ]`
             ตัวอย่าง: 1–9 none · 10–49 per_sheet 200 · 50+ percent 5
       (3) `discount_excluded_codes` = `["BW010","NW013"]` (รหัสที่ไม่เข้าร่วมส่วนลด)
       (4) `addons` = `[ {id, label, price, unit}, … ]` (glue 500 · glue_gun 600 · basin_stopper 0 · basin_install 5000)
       (5) `sale_types` = `[ {id, label, unit, needs:[…]}, … ]` (sheet · fabrication · set …)
       + `sheet_size` = `{width_mm, height_mm, …}` (ขนาดแผ่นมาตรฐานที่ใช้คิดพื้นที่)
  B. **แหล่งค่าเดียว (single source of truth)**: ค่าที่ส่งออก **ต้องเป็นค่าเดียวกับที่ตรรกะคิดราคาของแอปใช้** — ถ้าปัจจุบันค่าถูกฮาร์ดโค้ดหลายที่ ให้ **รวบมาเป็นค่าคงที่ชุดเดียว** แล้วให้ทั้ง (ก) ตัวคิดราคา และ (ข) ตัวส่งออก API อ่านจากชุดเดียวกัน
       ⚠️ **ห้ามเปลี่ยนค่าตัวเลขใด ๆ** — งานนี้คือ "ส่งออก" ไม่ใช่ "แก้ราคา" (ถ้าพบว่าค่าไม่ตรงกันระหว่างที่ต่าง ๆ **ให้รายงานก่อน อย่าแก้เอง**)
  C. **เทสต์กันหลุด 2 ชั้น**:
       (1) เทสต์ว่า `/api/catalog` มี 5 ก้อนนี้ + รูปแบบฟิลด์ถูกต้อง (มี `charge` เป็น number|null ฯลฯ)
       (2) เทสต์ **"ค่าเดียวกัน"**: ตัวเลขที่ API ส่งออก = ตัวเลขที่ตรรกะคิดราคาใช้ (เช่นเรียกฟังก์ชันคิดค่าดำเนินการแล้วเทียบ) — ถ้ามีคนแก้ข้างเดียว เทสต์ต้อง fail
  D. **ไม่แตะพฤติกรรมเดิม**: ฟิลด์เดิมของ `/api/catalog` (`sheetStones` · `installedStones` · `basins` …) ต้องคงเดิมทุกฟิลด์ + จำนวนเท่าเดิม (64/65/30)
  E. **รันชุดเทสต์**: `pnpm --filter @workspace/api-server test` + `typecheck` → แนบจำนวน pass/fail
  F. **รายงานตัวอย่าง payload**: `curl` ผลจริงจากเครื่องคุณ (หรือ dev) แล้วแนบเฉพาะ **5 ก้อนใหม่** (ตัดข้อมูลราคาสีออกเพื่อความกระชับ)
