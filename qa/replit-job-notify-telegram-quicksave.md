# ใบงาน Replit — รวมช่องทางส่งงาน 3 เรื่อง (เริ่มที่ Telegram ก่อน แล้วค่อยย้ายไป LINE)
สร้าง 14 ก.ย. 2026 · แอป Knight Basins · repo Knightfurnich/KnightBasins-Source

## หลักการสำคัญของรอบนี้
ทำช่องทางแจ้งเตือนเป็น **Telegram ก่อน** เพื่อให้ทดสอบได้จริงตอนนี้
แต่ต้องเขียนให้ **สลับไป LINE ทีหลังได้ด้วยการตั้งค่า ไม่ต้องรื้อโค้ด** (LINE กลุ่มยังไม่พร้อม)

ชื่อตัวแปรสภาพแวดล้อม (อ่านจาก env เท่านั้น · **ห้าม hardcode ลงโค้ดหรือ bundle**):
```
NOTIFY_CHANNEL=telegram          # ค่าเริ่มต้นรอบนี้ · ทีหลังเปลี่ยนเป็น line ได้
TELEGRAM_BOT_TOKEN=...           # เดวิดตั้งให้บน VPS เอง
TELEGRAM_SALES_CHAT_ID=...       # เดวิดตั้งให้บน VPS เอง
LINE_CHANNEL_ACCESS_TOKEN=...    # ของเดิม (ยังไม่ใช้รอบนี้ แต่โค้ดต้องยังอยู่)
```
ถ้า env ไม่ครบ → **ห้ามทำให้การส่งใบเสนอราคา/แบบร่างล้มเหลว** ให้บันทึกข้อมูลสำเร็จเสมอ แล้วแจ้งในหน้าจอว่า "บันทึกแล้ว แต่ยังไม่ได้ส่งแจ้งเตือน"

---

## งาน A: ใบเสนอราคาโหมด "ซื้อด่วน" ต้องบันทึกและแชร์ลิงก์ได้
ตอนนี้หน้า `/quote` (ซื้อด่วน) มีแค่พิมพ์ PDF กับคัดลอกสรุปส่ง LINE — **ไม่มีลิงก์ให้ส่งลูกค้า** และไม่บันทึกเป็นใบที่เปิดซ้ำได้ ต่างจากโหมด 2D

ต้องทำ:
1. กด "ออกใบเสนอราคาทางการ" → บันทึกลงฐานข้อมูลจริง **ใช้ตาราง `customer_leads` + คอลัมน์ `quote_number`/`studio_data` เดิม ไม่สร้างตารางใหม่**
2. ออกเลขที่ใบเสนอราคารูปแบบเดียวกับโหมด 2D · ส่งซ้ำด้วย `leadKey` เดิมต้องได้เลขเดิม
3. พาไปหน้า `/quote/view?quote=...` หน้าเดียวกับของโหมด 2D (ใช้ component เดิม)
4. มีปุ่ม **"คัดลอกลิงก์ใบเสนอราคา"** บนหน้านั้น
5. เปิดได้แบบ read-only โดยไม่ต้องล็อกอิน (ใช้ endpoint สาธารณะเดิม)
6. หน้าใบเสนอราคาที่เปิดซ้ำต้องเห็นรายการหิน/อ่าง/ค่าติดตั้ง/ค่าดำเนินการ และยอดรวมเท่าเดิม

## งาน B: ปุ่ม "ส่งแบบเข้า Telegram" (เดิมตั้งใจเป็น LINE)
บนหน้าใบเสนอราคาที่บันทึกไว้ **และ** หน้า `/quote` เพิ่มปุ่ม "ส่งเข้า Telegram"
- กดแล้วส่งข้อความสรุปเข้าแชตทีมขาย: เลขที่ใบเสนอราคา · ชื่อลูกค้า/โครงการ · รายการ · ยอดรวม · ลิงก์ read-only
- ส่งผ่าน Telegram Bot API (`sendMessage`) ตาม env ข้างบน
- แสดงผลในหน้าจอทันที: ส่งสำเร็จ / ส่งไม่สำเร็จ (พร้อมเหตุผล) — ห้ามเงียบ
- กดซ้ำได้ (ส่งซ้ำได้ ไม่พัง)

## งาน C: โหมด "ส่งแบบร่างด้วยมือ" ให้แจ้งเตือนทาง Telegram
- ลูกค้าแนบรูปวาดมือ + กรอกข้อมูล → ต้องบันทึกสำเร็จเสมอ
- ส่งเข้า Telegram เป็น **รูปภาพ + คำบรรยาย** (`sendPhoto`) โดยใช้ URL รูปที่ระบบออกให้อยู่แล้ว · คำบรรยายมีชื่อ/โทร/โครงการ/รุ่นอ่างที่สนใจ/ลิงก์หน้าใบเสนอราคา (ถ้ามี)
- แสดงสถานะส่งในหน้าจอ: "ส่งแบบร่างให้ทีมขายแล้ว" หรือ "บันทึกแล้ว แต่ยังไม่ได้แจ้งเตือน"

## เกณฑ์ตรวจรับ (แนบหลักฐานจริงทีละข้อ)
1. ซื้อด่วน → กดออกใบเสนอราคา → ได้เลขที่ + หน้าลิงก์ที่เปิดซ้ำได้ (แนบภาพ)
2. รีเฟรช/เปิดลิงก์ซ้ำ → รายการและยอดเท่าเดิม (แนบภาพก่อน-หลัง)
3. ปุ่มคัดลอกลิงก์ทำงาน และลิงก์เปิดได้โดยไม่ล็อกอิน (แนบภาพ)
4. กด "ส่งเข้า Telegram" → ข้อความมาถึงจริง พร้อมข้อความยืนยันบนหน้าจอ (แนบภาพหน้าอ + ภาพข้อความที่ได้รับ)
5. ส่งแบบร่างด้วยมือ → รูป + ข้อความมาถึง Telegram (แนบภาพ)
6. ตั้ง env `NOTIFY_CHANNEL` เป็นค่าว่าง/ไม่มี token → การส่งใบเสนอราคายังสำเร็จ และขึ้นข้อความว่าไม่ได้แจ้งเตือน (แนบภาพ)
7. โหมด 2D เดิมยังทำงานเหมือนเดิม: ลากวาง snap 50 มม. · ลิงก์ที่บันทึกไว้เปิดได้ · ห้ามหักพื้นที่ช่องเจาะอ่าง (แนบภาพ)

## ห้ามแตะ
- Auth / Session · Admin Guard · Persona น้องไนท์
- ข้อมูลอ่างและราคาในฐานข้อมูล · รุ่นกลมต้องเป็น Ø ห้าม D
- กฎราคา: ห้ามหักพื้นที่ช่องเจาะ · ห้ามบวกค่าขอบ · อ่างคิดเป็นใบ · ติดตั้ง 5,000/ชุด ฟรีเมื่อ 3 ชุด
- **ห้ามใส่ token ใด ๆ ลงโค้ดหรือ bundle** (เดวิดตั้งใน env บน VPS)
