# ข้อความส่ง Replit (รอบ 2) — คัดลอกวางได้เลย

แนบมา 2 ไฟล์: `replit-patch-round2.diff` (ตัว patch) และ `replit-patch-round2.md` (วิธีใช้ + หลักฐาน + เกณฑ์ตรวจ)

## 1) apply patch นี้ก่อน
```
git apply replit-patch-round2.diff
```
ตรวจแล้วว่า apply ผ่านทั้ง 3 ไฟล์บน commit `ad1f47c` (เราเทสต์ `git apply --check` เองแล้ว)

patch แก้ 2 เรื่อง
- `sink-geometry.ts` — รับ prefix วงกลม `D d Ø ø ⌀` ด้วย (เดิมรับแค่ `Ø`) กันอ่างกลมถูกวาดเป็นสี่เหลี่ยมอีกครั้ง
- `design.tsx` — ช่องค้นหาสี: ค้น "รหัส" แบบ substring + เรียงรหัสที่ตรงเป๊ะขึ้นก่อน
  (เดิมพิมพ์ `SG` หรือ `420` ได้ 0 รายการ · `KZ802` กับ `KZ802N` ต้องยังเป็นคนละสี ห้ามยุบรวม)

## 2) เรื่องที่ยังไม่ได้ทำ — เปิด draft กลับเข้าหน้าออกแบบ
ตอนนี้ save draft แล้วไป `/quote/<id>` แต่หน้าออกแบบโหลด draft ได้เฉพาะเมื่อ URL มี `?quoteId=<id>`
อยากให้มีปุ่ม/ลิงก์ **"แก้ไขต่อในหน้าออกแบบ"** จาก draft ที่บันทึกแล้ว (หรือจำ draft ล่าสุดแล้วโหลดให้เมื่อเข้า `/design`)

เกณฑ์ตรวจรับ: save draft → กดปุ่ม → อยู่ในหน้าออกแบบที่โหลด draft นั้นจริง (อ่างที่เลือก + ตำแหน่งช่องเจาะที่ลากไว้ต้องครบ)

## 3) หลัง apply + deploy ส่งหลักฐานกลับ
```
- พิมพ์ "SG" และ "420" ในช่องค้นหาสี -> ต้องเจอ SG 420 (เดิม 0 รายการ)
- พิมพ์ "KZ802" -> KZ802 ขึ้นก่อน KZ802N และเป็น 2 การ์ดแยกกัน
- KF023 -> ช่องเจาะเป็นวงกลม (กว้าง = สูง = 0.35 ม.)
- KF003 -> ยังเป็นสี่เหลี่ยม 0.35 x 0.50 ม. · KF029 -> ยังขึ้น "ขนาดหลุมอ่างไม่ระบุในแคตตาล็อก"
- ราคา 0.60 x 1.80 SG420 กทม. ต้องยังเป็น 14,180 / VAT 992.6 / รวม 15,172.6
```
รายงานเป็นตาราง: ข้อ | สถานะ | ไฟล์ที่แก้ | หลักฐานจริง (คำสั่ง + ผลที่วัดได้) — ห้ามรายงานว่า "ผ่าน" ลอย ๆ

⛔ **ห้ามแตะ auth/ล็อกอิน · ห้ามเปิด bypass ใด ๆ · ห้ามแก้ persona ของผู้ช่วยในเว็บ**
(ตอนนี้เป็นเสียงหญิง ใช้ ค่ะ/คะ และชื่อที่แสดงคือ "น้องไนท์" — อย่าให้หลุดกลับเป็น ครับ)
