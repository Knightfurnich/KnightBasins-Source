# ใบงานส่ง Replit — ปรับปรุง UI แผงน้องไนท์, ซูมรูปสินค้า และฟีเจอร์ช่วยขาย (v1)

> 13 ก.ย. 2026 · รวมงานปรับปรุงตามความต้องการของเจ้าของและข้อเสนอแนะทีมขาย

---

## 1. UI แผงน้องไนท์ (KnightSupport Panel)
- **Auto-resize Workspace:** บน Desktop เมื่อเปิดแผงน้องไนท์ ให้พื้นที่ทำงานตรงกลาง (Plan Studio / Canvas) **ปรับขนาดความกว้างอัตโนมัติ** ให้พอดีกับพื้นที่ที่เหลือ โดยไม่โดนแผงทับ และไม่ทำให้องค์ประกอบภายในพื้นที่ตรงกลางเบี้ยวหรือเรียงตัวผิดปกติ
- **Chat Timeline & History:** 
  - ปรับ UI สนทนาของน้องไนท์เป็นรูปแบบ **Chat Timeline** (กล่องข้อความฝั่งผู้ใช้ และฝั่งน้องไนท์ คล้าย LINE / Telegram)
  - ดึงประวัติการสนทนาย้อนหลัง (Chat History) มาแสดงได้ ไม่หายเมื่อปิด/เปิดแผง หรือสลับหน้า
  - มี Scrollbar เลื่อนดูข้อความเก่าด้านบน และ Auto-scroll ลงล่างสุดเมื่อมีข้อความใหม่

## 2. ระบบซูมรูปภาพสินค้า (Image Lightbox / Modal)
- **Click to Zoom:** บนการ์ดสินค้าทุกใบ (ทั้งใน `/catalogue` และแผงน้องไนท์) เมื่อกดที่ตัวรูปภาพ ให้เปิด Lightbox / Modal ป๊อปอัพแสดงภาพขนาดใหญ่ซูมชัดเจน
- **Slab View:** หากมีทั้งภาพ Swatch และภาพแผ่นใหญ่ (`slabImageUrl`) ให้มีปุ่ม/แท็บสลับดูภาพแผ่นใหญ่ได้ใน Modal เดียวกัน
- **Separate Click Action:** กดที่ตัวรูปภาพ = เปิดดูภาพขยายเท่านั้น (ไม่เป็นการกดเลือกสินค้า) / กดที่ชื่อสินค้า หรือปุ่ม `>` = เลือกสินค้าตามปกติ

## 3. ฟีเจอร์สนับสนุนทีมขายเพื่อปิดการขาย (Sales Enablement)
- **Copy & Share Quote Link:** บนหน้า `/quote/:id` เพิ่มปุ่ม **"คัดลอกลิงก์ส่งให้ลูกค้า"** (data-testid="button-share-quote") กดแล้วคัดลอก URL สำหรับส่งให้ลูกค้าดูแบบ Read-only ได้ทันที
- **Share Design to LINE:** บนหน้าออกแบบ (`/design`) เพิ่มปุ่ม **"ส่งแบบเข้า LINE"** สำหรับส่งการ์ดสรุปแบบ + ราคา ให้ลูกค้าใน LINE แชต
- **Smart Colour Search:** ช่องค้นหาสีใน Catalogue และหน้าออกแบบ ต้องค้นเจอแม้พิมพ์ต่างฟอร์แมต โดยมองข้ามเว้นวรรคและตัวพิมพ์เล็ก-ใหญ่ (เช่น `SG420`, `SG 420`, `sg420` หรือพิมพ์ชื่อสี `Bright White` ต้องเจอผลลัพธ์เดียวกัน)
- **Brand / Series Badges:** แสดงป้ายกำกับยี่ห้อ/ซีรีส์เล็กๆ (เช่น Lotte Staron, Zen Stone, Navis) บนการ์ดสีใน Catalogue เพื่อให้ทีมขายอธิบายลูกค้าได้ง่ายขึ้น

## เกณฑ์ตรวจรับ (แนบหลักฐานจริง)
```
1. เปิดแผงน้องไนท์แล้วพื้นที่ตรงกลางยืด-หดพอดีอัตโนมัติ ไม่โดนแผงทับ (แนบภาพ)
2. UI แชทน้องไนท์เป็น Timeline คล้าย LINE/Telegram + เลื่อนดูประวัติข้อความเก่าได้ (แนบภาพ)
3. กดที่รูปภาพสินค้าแล้วมี Lightbox แสดงภาพขยายใหญ่ชัดเจน + สลับดูภาพแผ่นใหญ่ (Slab) ได้ (แนบภาพ)
4. หน้า /quote/:id มีปุ่มคัดลอกลิงก์อ่านอย่างเดียวส่งให้ลูกค้า (แนบภาพ)
5. ช่องค้นหาสีพิมพ์ "SG420", "SG 420", "sg420" ได้ผลลัพธ์ตรงกันทั้งหมด (แนบภาพ)
6. การ์ดสีใน Catalogue แสดง Badge ยี่ห้อ/ซีรีส์ชัดเจน (แนบภาพ)
```
