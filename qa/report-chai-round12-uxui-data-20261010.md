## 4. ฟอร์มและข้อความ (ข้อ 4)

## 6. ข้อค้นพบ เรียงตามความรุนแรง (ข้อ 5/8)

### F1 · สูง · ใบเสนอราคาแบบ "หินอย่างเดียว" ออกไม่ได้ ทั้งที่หน้าโชว์ยอดรวม
- ผู้ใช้เห็น: เลือกหินที่ `/stone` → "ดูใบเสนอราคา" → `/quote` แสดง ฿5,400 + VAT ฿378 = **฿5,778** แต่ปุ่ม "บันทึกและส่งเข้า Telegram" **disabled** (วัดจาก DOM: `disabled:true`) และมีข้อความ "เพิ่มสินค้าอย่างน้อย 1 รายการก่อนออกใบเสนอราคา"; ปุ่ม "ออกใบเสนอราคาทางการ" **ดูเหมือนกดได้** (`disabled:null`) แต่กดแล้วแค่เลื่อนไปที่ข้อความนั้น (`saveQuote` → `focusQuoteRequirement`, `App.tsx:1641-1646`)
- ต้นเหตุ: `canGenerate = … && cart.length > 0` (`App.tsx:1542`) นับเฉพาะอ่าง ไม่นับหิน
- ผลกระทบ: ลูกค้าที่มาแบบ "สั่งตัดท็อปอย่างเดียว/ซื้อแผ่น" (หน้าที่โฆษณาเป็นสินค้าหลักของ `/stone`) เสียโอกาสขายโดยไม่มีใครบอกเหตุผลที่เข้าใจได้
- ข้อเสนอ (ไม่แก้เอง): ให้เดวิดตัดสินกับบอสว่าจะอนุญาตใบเสนอราคาที่มีเฉพาะหิน (แก้เงื่อนไข) หรือคงไว้แต่เปลี่ยนข้อความเป็น "ต้องมีอ่างอย่างน้อย 1 รุ่นเพื่อออกใบเสนอราคาออนไลน์ — สั่งหินอย่างเดียวโทร … หรือกด 'ให้ทีมโทรกลับ'" และ disable ปุ่ม "ออกใบเสนอราคาทางการ" ให้เหมือนปุ่มข้างๆ

### F2 · สูง · ประมาณการโหมดติดตั้งต่ำกว่าที่จะถูกคิดจริง และไม่รวมค่าดำเนินการที่หน้าเดียวกันประกาศ
- ผู้ใช้เห็น: `/stone` โหมดติดตั้ง ค่าเริ่มต้น 60×120 ซม. = 0.72 ตร.ม. ราคา ฿7,500/ตร.ม. → "ประมาณการ **฿5,400**" และ "ค่าแรงติดตั้ง รวมในราคาแล้ว" · `/quote` ยอดรวม **฿5,778** (รวม VAT)
- ในหน้าเดียวกันมีบรรทัดเล็ก: "ขั้นต่ำ 5 m² (กทม.) / 10 m² (ตจว.) … งานต่ำกว่าขั้นต่ำคิดค่าดำเนินการ ฿5,000 / ฿8,000" และเงื่อนไขใบเสนอราคา (`App.tsx:954-965`) ยังบอกว่าพื้นที่น้อย "คิดเหมาที่ 1 ตรม. (กทม.) / 3 ตรม. (ตจว.)"
- ตัวเลขที่เห็นไม่รวมทั้งค่า ฿5,000 และการคิดขั้นต่ำ — ถ้าคิดตามข้อความของหน้าเอง ยอดก่อน VAT ต่ำสุดจะเป็น ≥ ฿10,400 (5,400+5,000) และถึง ฿12,500 (7,500×1+5,000) ถ้าใช้กฎ 1 ตร.ม. — **ผมไม่ได้ยืนยันว่ากฎ 1/3 ตร.ม. ใช้ร่วมกับค่าดำเนินการหรือไม่** (ต้องให้เจ้าของธุรกิจ/เดวิดตอบ) ตัวเลขช่วง 10,400–12,500 เป็นการคำนวณจากข้อความบนหน้า ไม่ใช่ราคาจริงจากระบบ
- ข้อเสนอ: ทำให้ตัวประมาณการแสดงค่าดำเนินการเมื่อต่ำกว่าขั้นต่ำ (หรือเปลี่ยนป้ายเป็น "ราคาวัสดุตามพื้นที่ — ยังไม่รวมค่าดำเนินการงานเล็ก") และเลือกหน้าที่ลูกค้าอยู่ (กทม./ตจว.) ก่อนโชว์ตัวเลข
