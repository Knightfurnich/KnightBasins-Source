## งานที่ 1 — วาดช่องเจาะอ่างตามขนาดจริง

**ปัจจุบัน**
```js
// design.tsx:538
const sinkPosition = selectedPiece ? {
  left: `${(selectedPiece.x + selectedPiece.width  * 0.57) * stageScale}px`,
  top:  `${(selectedPiece.y + selectedPiece.depth  * 0.5 ) * stageScale}px`
} : undefined;
```
ตำแหน่ง 57% / 50% ฝังตายตัว ไม่เกี่ยวกับขนาดอ่างจริง และลากย้ายไม่ได้

**ต้องทำ**
1. แปลง `bowlMm` เป็นเมตร แล้ววาดสี่เหลี่ยม/วงกลม ตามขนาดจริงบนผัง
   - "350x500x130" -> กว้าง 0.35 ม. · ยาว 0.50 ม. (ไม่ต้องใช้ 130 = ความลึก)
   - "Ø350x150"    -> วงกลม Ø 0.35 ม.
2. ลูกค้าลากย้ายตำแหน่งช่องเจาะได้ (ลากอยู่บนชิ้นงาน)
3. ตำแหน่งต้องถูกบันทึกใน draft และโหลดกลับมาได้
4. ถ้า `bowlMm` เป็น null -> วาดเป็นสัญลักษณ์แทน + ข้อความ "ขนาดหลุมอ่างไม่ระบุในแคตตาล็อก"
   ห้ามเดาขนาดเอง

**เกณฑ์ตรวจรับ**
```
1. เลือก KF003 -> ช่องเจาะบนผังกว้าง 0.35 ม. ยาว 0.50 ม. (วัดจาก DOM ได้)
2. เลือก KF023 (กลม) -> เป็นวงกลม Ø 0.35 ม.
3. เลือก KF029 -> ไม่วาดขนาด + แสดงข้อความ "ไม่ระบุ"
4. ลากช่องเจาะ -> ตำแหน่งเปลี่ยน · บันทึก draft -> โหลดกลับ -> ตำแหน่งเดิม
5. ราคา/พื้นที่ต้องไม่เปลี่ยนจากตอนที่ยังไม่เลือกอ่าง
```

## งานที่ 2 — เลือกอ่างได้มากกว่า 1 ตัว

**ปัจจุบัน** `sinkModelCode?: string` = อ่างเดียวต่อหนึ่งแบบ
**แต่** แคตตาล็อกของบริษัทเอง (หน้า KF003) โชว์เคาน์เตอร์อ่างคู่ -> งานจริงมี 2 อ่าง

**ต้องทำ**
1. เปลี่ยนเป็นเก็บเป็นรายการ (แต่ละชิ้นงานมีอ่างของตัวเอง หรือมีรายการอ่างต่อแบบ)
2. เพิ่ม/ลบอ่างได้ · เลือกได้ว่ารุ่นไหนอยู่ตรงไหน
3. หน้าจอแสดงอ่างที่เลือกครบทุกตัว + ขนาด
4. draft เก็บและโหลดกลับได้ครบ

**ข้อกำหนดที่ห้ามละเมิด**
```
- ราคายังคงไม่เปลี่ยนตามจำนวนอ่าง (ค่าช่องเจาะรวมในเรต ตร.ม. แล้ว)
- ถ้าอนาคตจะคิดค่าอ่างเพิ่ม ต้องรอเจ้าของยืนยันก่อน ห้ามคิดเอง
- จำนวนอ่างต้องถูกส่งไปกับ draft เพื่อให้ทีมขายเห็น
```

**เกณฑ์ตรวจรับ**
```
1. เลือก KF003 หนึ่งตัว -> ทุกอย่างเหมือนเดิม (ไม่ regress)
2. เพิ่มอ่างตัวที่ 2 (KF012) -> แสดง 2 ตัวบนผัง พร้อมขนาดแต่ละตัว
3. ลบตัวใดตัวหนึ่ง -> เหลือตัวที่ถูกต้อง
4. บันทึก draft -> โหลดกลับ -> ได้ 2 อ่างเหมือนเดิม
5. ราคายังเป็น 14,180 ในเคสทดสอบเดิม
```
