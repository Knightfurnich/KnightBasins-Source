## โมเดลใหม่: ประกอบผังจากสี่เหลี่ยม (สำคัญ — อ่านก่อน)
ช่างตัดเคาน์เตอร์เป็น **แผ่นสี่เหลี่ยม** แล้วนำมาประกอบเป็นตัว L / U / I
ตัวอย่างจริงของผู้ใช้: ตัว L = 2 แผ่น → `1420 × 620` + `3170 × 620` = **2.8458 ตร.ม.**
**ไม่มีการเลือก "ทรง" แล้ว** — รูปทรงเกิดจากจำนวน/การจัดวางสี่เหลี่ยมเอง

ข้อกำหนดโมเดล:
1. 1 ใบเสนอราา = **สูงสุด 3 ชิ้นงาน**
2. 1 ชิ้นงาน = ประกอบจากสี่เหลี่ยม **สูงสุด 6 อัน**
3. แต่ละสี่เหลี่ยม: กรอก **กว้าง × ยาว (มม.)** และสลับ **แนวนอน / แนวตั้ง** ได้
4. จัดเรียงบนผังได้ · ขอบที่ชนกันให้ snap ต่อกัน · ถ้าสี่เหลี่ยมซ้อนทับกันให้แจ้งเตือน (ห้ามคิดพื้นที่ซ้ำ)
5. **พื้นที่งาน = ผลรวมพื้นที่สี่เหลี่ยมทุกอัน** (ไม่หักมุมเอง เพราะผู้ใช้กำหนดขนาดแผ่นเอง)
   เคสทดสอบ: 1420×620 + 3170×620 = 2.8458 · 2040×760 = 1.5504 · รวม 4.3962 ตร.ม.
6. ชิ้นงานที่มีขั้น/รอยบาก = อีกสี่เหลี่ยมหนึ่งอัน **ต้องวาดได้ตามจริง** (ไม่ใช่แสดงแค่สี่เหลี่ยมฐาน)
7. **ยกเลิกกฎระยะขอบ 50 มม.ทั้งหมด** — ไม่วาด ไม่เตือน ไม่บล็อกการส่ง (แบบนี้ใช้ให้ช่าง/ลูกค้าดู ไม่ได้เอาไปทำ nesting)
8. เส้นประ = **แนวรอยต่อระหว่างแผ่น** และต้องระบุว่า "ต่อแผ่นแล้วต้องได้ฉาก 90°"
9. โหมดด่วน (สำหรับลูกค้าทั่วไป) ยังคงติ๊ก "มีบัวด้านหลัง" แบบเดิมได้

## ความหมายสัญลักษณ์ (วาดให้ตรง)
| สัญลักษณ์ | ความหมาย | มีผลต่อราคา |
|---|---|---|
| ▲ สามเหลี่ยม | ติดตั้งบัวตลอดแนวนั้น | ใช่ (คิด ตร.ม. ตามเรตสี) |
|  วงกลมกากบาท | ขอบเปิดโชว์ตามแนวนั้น ขนาด 24/30 มม. | ใช่ (คิดเป็นเมตร) |
| ขีดคู่ | ด้านเท่ากัน + ชิดผนัง ไม่ใช่ขอบเปิดโชว์ | ไม่มีผลต่อราคา |
| เส้นประ | แนวรอยต่อระหว่างแผ่น ต้องได้ฉาก 90° | ไม่มีผลต่อราคา |
| เส้นบอกขนาด | ขนาดครบทุกด้าน หน่วย มม. | ไม่มีผลต่อราคา |

- ตั้งสถานะรายด้านได้ทีละด้าน: **ติดบัว / ขอบเปิด / ชิดผนัง / ปกติ** (ด้านเดียวมีสถานะเดียวเท่านั้น)
- ด้านที่ใช้ร่วมกันระหว่างแผ่นที่ชนกัน **นับครั้งเดียว** และตั้งสถานะครั้งเดียว
- สถานะรายด้านผูกกับแต่ละชิ้นงาน และติดไปกับใบเสนอราคา + ข้อความ Telegram

## ราคา (ผู้ใช้ยืนยันแล้วทุกข้อ)
1. **หิน** = พื้นที่งาน × เรตสีที่เลือก (ตามเดิม)
   - ️ **สีเรต 9,500 (ลายหินอ่อน สายแร่) เล่มระบุฐาน = "แผ่นตัด"** → เสนี้ **ห้ามคิดอัตโนมัติ** ให้แสดงคำเตือน "สีลายหินอ่อนคิดตามแผ่นตัด ทีมขายจะคิดให้" และไม่รวมยอดอัตโนมัติ
2. **บัว** = (ความยาวแนวบัว × ความสูงบัว) × **เรตสีที่เลือก** (ไม่ต้องมีเรตบัวแยก)
   - ความสูงบัว **default 120 มม.** แก้ไขได้ · ห้ามเป็นค่าว่าง (ถ้าว่าง → ไม่คิดเงินบัว + แสดงคำเตือน)
3. **ขอบเปิด** = ความยาว × ราคาต่อเมตร (**ทีมขายกรอกเอง**)
   - ว่าง = ยังไม่กรอก → แสดงคำเตือน · `0` = ตั้งใจฟรี → แสดง "ฟรี" ไม่เตือน · ติดลบ = ห้าม · ทศนิยม 2 ตำแหน่ง
4. **ค่าดำเนินการงานพื้นที่เล็ก** ตาม KB: กทม./ปริมณฑล พื้นที่งาน < 5 ตร.ม. = 5,000 · ต่างจังหวัด < 10 ตร.ม. = 8,000
   - พื้นที่งาน = พื้นที่เคาน์เตอร์ + พื้นที่บัว
5. **ส่วนลด** — ต้องมีช่องส่วนลด (ก่อน VAT) และยังมีสิทธิ์ติดตั้งฟรีเมื่ออ่างครบ 3 ชุดตามเดิม
6. **VAT 7%** = คิดจากยอด **หลังหักส่วนลดทั้งหมด** (รวมส่วนลดติดตั้งฟรี + ส่วนลดที่กรอก) + ค่าดำเนินการงานพื้นที่เล็ก
7. **การปัดเศษ**: คูณด้วยค่าละเอียด (ห้ามใช้ค่าที่ปัดแล้วคูณ) → **ปัดเป็นจำนวนเต็มบาททีละบรรทัด แล้วจึงรวมยอด**
8. **อ่าง** ตามเดิมทุกข้อ: คิดเป็นใบ · ค่าติดตั้ง 5,000/ชุด · ฟรีเมื่อ 3 ชุด · ห้ามหักพื้นที่ช่องเจาะอ่าง

## กติกาที่ต้องคงไว้ (จากช่องโหว่ที่ตรวจแล้ว 22 ข้อ)
- ตัวเลข 2.8458 / 1.5504 / 4.3962 / 4.08 / 4.59 = **เคสทดสอบเท่านั้น** ห้าม hard-code
- **ใบเสนอราคาเก่า้องล็อกทุกค่าใน snapshot** (พื้นที่ · ความยาวบัว · ความสูงบัว · ความยาวขอบ · ราคาหิน · ราคาขอบ · ค่าติดตั้ง · ค่าดำเนินการ · ส่วนลด · VAT · ยอดรวม · คำเตือน) และหน้าใบเสนอราคาห้ามดึงราคาปัจจุบันมาคิดใหม่
- **บอท LINE / ฝั่งเดวิด**: ห้ามตอบราคาบัว/ขอบจาก KB (ไม่มีเรต) และห้ามคิดราคาสีเรต 9,500 จากพื้นที่งาน
- ใบที่ไม่มีบัว/ขอบเลยต้องออกได้ตามปกติ (งานด่วนต้องไม่พัง)
- โหมดด่วน ↔ ละเอียด: ไม่ลบค่าที่ตั้งไว้เมื่อสลับไปมา

## DXF / PDF
- DXF หน่วยมิลลิเมตรแท้ (`$INSUNITS = 4`) เปิดใน SketchUp ได้สเกล 1:1
- เลเยอร์: `PIECE_OUTLINE` · `PANEL_JOINT` (เส้นประ) · `UPSTAND` (▲) · `OPEN_EDGE` (⊗) · `WALL_FLUSH` (ขีดคู่) · `BASIN_HOLES` · `BASIN_LABELS` · `DIMENSIONS` · `NOTE`
- **ห้ามมีเลเยอร์/เส้น CLEARANCE_50 ในไฟล์ส่งออกทุกช่องทาง**
- NOTE ภาษาอังกฤษ ASCII ล้วน: `REFERENCE DRAWING ONLY - NOT FOR PRODUCTION OR CNC. VERIFY ON SITE BEFORE FABRICATION.`
- PDF ใช้ทางพิมพ์ของเบราว์เซอร์ (เวกเตอร์ + ฟอนต์ไทยจากเบราว์เซอร์) ตั้งชื่อหน้าเว็บเป็น `KF-Basins-<เลขที่หรือชื่อโครงการ>-<จำนวนชิ้นงาน>ชิ้น` ก่อนพิมพ์ แล้วคืนค่าหลังพิมพ์เสร็จ
- เทสต์เดิมต้องยังผ่าน: $INSUNITS = 4 · NOTE ASCII · ไม่มีเส้น 50 มม.

## เกณฑ์ตรวจรับ (แนบหลักฐานจริงทีละข้อ)
1. เพิ่ม 2 สี่เหลี่ยม (1420×620 + 3170×620) จัดเป็นตัว L ได้ → พื้นที่ 2.8458 ตร.ม. (แนบภาพ)
2. สลับแนวนอน/แนวตั้งของสี่เหลี่ยมได้ และสี่เหลี่ยมซ้อนกันมีคำเตือน (แนบภาพ)
3. 1 ใบมี 3 ชิ้นงานได้ (แนบภาพ)
4. ชิ้นงานที่มีขั้น/รอยบาก (เช่น 2040×760 + ขั้น) วาดได้ตามจริง และพื้นที่ถูกต้อง (แนบภาพ)
5. ตั้งสถานะรายด้าน (▲/⊗/ขีดคู่) → วาดถูกตำแหน่ง และความยาวรวมถูกต้อง (บัว 4.08 ม. · ขอบ 4.59 ม.) (แนบภาพ + ตัวเลข)
6. ไม่มีเส้น 50 มม. ที่ไหนเลย และ**วางอ่างชิดขอบได้โดยไม่ถูกบล็อก** (แนบภาพ)
7. เส้นประที่รอยต่อระหว่างแผ่น + ข้อความ "ต้องได้ฉาก 90°" (แนบภาพ)
8. ความสูงบัว default 120 มม. แก้ไขได้ · ว่างไม่ได้ (แนบภาพ)
9. ราคาขอบ 300/ม. → ยอดถูกต้องแยกบรรทัด · ว่าง → เตือน · 0 → แสดง "ฟรี" (แนบภาพ)
10. เลือกสีเรต 9,500 → ขึ้นคำเตือน "คิดตามแผ่นตัด ทีมขายจะคิดให้" และไม่รวมยอดอัตโนมัติ (แนบภาพ)
11. ส่วนลดกรอกได้ และ VAT คิดจากยอดหลังหักส่วนลด (แนบภาพ)
12. ยอดเงินปัดเป็นบาทถ้วนทีละบรรทัด (แนบภาพ)
13. เปิดใบเสนอราคาเก่า → ยอดไม่เปลี่ยน (แนบภาพ)
14. DXF: $INSUNITS=4 · เลเยอร์ครบตามรายการ · NOTE ASCII · ไม่มีเส้น 50 มม. (แนบภาพ + ผลตรวจไฟล์)
15. ข้อความ Telegram แสดงความยาวบัว/ขอบ และจำนวนชิ้นงาน (แนบภาพ)
16. เทสต์ทั้งหมด + build/asset guard ผ่าน (แนบผลรัน)
