## สิ่งที่ทำ
- **A (ตัวช่วยกลางตัวเดียว):** `catalog.ts` ถือตารางเดียว (`MACHINE_CATEGORY_WORDING`: counter basin→เคาน์เตอร์ · tall vertical washbasin→ทรงสูง · storage→เสาวางของตั้งพื้น) + `knownCategoryWording` · `isMachineCategoryId` · `customerCategoryWording` · **`customerCategoryLabel(label, fallback)`** (ใหม่: ป้ายที่ trim แล้ว ถ้าว่าง/เป็น id ดิบ → fallback) · JSON-LD เรียก `customerCategoryLabel(product.categoryLabel, STORAGE_CATEGORY_LABEL)` · UI import จากตัวเดียวกัน — ไม่มีสำเนาที่ 2/3 (มีเทสต์ตรวจ)
- **B:** เฉพาะ `category === "counter basin"` พิมพ์ "ขนาดเคาน์เตอร์ …" · ทรงสูง/เสาวางของ/หมวดอื่นที่ไม่รู้จัก พิมพ์ "ขนาด …" · ชนิดสินค้า ("อ่างล้างหน้าหินสังเคราะห์" / ป้ายเสา) และ "หลุมอ่าง" ของทรงสูงไม่เปลี่ยน · ไม่พิมพ์คำเพิ่ม
- **นิยาม "id ดิบ":** ใช้กติกาเดียวกับ UI (3 id ที่ระบบรู้จัก ไม่สนตัวพิมพ์/ช่องว่าง) ไม่ใช่ "อังกฤษล้วนทุกคำ" เพื่อไม่เปลี่ยนพฤติกรรม UI และไม่เดา — ป้ายอังกฤษอื่นที่ API ส่งมา (ถ้ามี) ยังแสดงตามที่ส่ง
