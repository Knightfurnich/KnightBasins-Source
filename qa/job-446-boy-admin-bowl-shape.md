> 2. **โดเมนค่า:** รหัสเครื่อง `rounded-rectangle` · `oval` · `round` · `rectangle` · `square` · `rounded-square` + **`null` = ไม่ระบุ** (คำว่า "กลม" = `round` มีอยู่แล้ว)
> 3. **`bowlShapeLabel` = (ก) คำนวณในโค้ดจากรหัส** — แอดมินเก็บแค่รหัส ไม่เก็บข้อความไทย (กันพิมพ์ผิด/แก้ที่เดียว) ⇒ ฝั่งคุณ **แสดงค่าที่ API ส่งมา ห้ามพิมพ์คำเอง**
> 4. **endpoint:** `PUT /api/admin/basins/:id/bowl-shape` สิทธิ์ `basins/edit` · `GET /api/admin/basins` ส่ง **`bowlShapeSource`** = **`database` หรือ `none` เท่านั้น** (ชัยแจ้ง 11 ต.ค. 69 — **เลิกใช้ค่า `builtin`** แล้วหลัง 449-C) ให้แสดงที่มา
> 5. **`null` บันทึกได้ = ไม่ระบุ** · ⚠️ ถ้าคอลัมน์เป็น null และตารางในโค้ดมีค่า ⇒ ระบบจะใช้ **ค่าตั้งต้นของโค้ด** (ไม่ซ่อนบรรทัด) ⇒ ให้แสดงกำกับว่า "(ค่าตั้งต้นของระบบ)" เพื่อไม่ให้สับสน · ถ้าบอสต้องการ "ล้าง = ซ่อนจริง" จะเป็นใบแยก (ยังไม่ออก)
