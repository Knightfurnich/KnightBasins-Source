- จาก `หินสังเคราะห์.com` → `/quote` : **“ขอใบเสนอราคาท็อปครัวหินสังเคราะห์”**

**กติกาสำคัญ**
1. ต้องเป็นลิงก์ **follow** (ห้ามใส่ `rel="nofollow"`) — ลิงก์ nofollow แทบไม่มีผลต่อ SEO
2. วางใน **เมนู / footer / เนื้อหาบทความ** ที่ผู้ใช้มองเห็น (ไม่ซ่อน)
3. **1–3 ลิงก์ต่อเว็บพอ** และควรเป็นหน้าต่าง ๆ กัน (ไม่ชี้หน้าเดียวซ้ำ ๆ)
4. ไม่ต้องซื้อ/แลกลิงก์แบบผิดกติกา — สองเว็บนี้เป็นของเราอยู่แล้ว = “ลิงก์คุณภาพ” ธรรมชาติ

## 3) วิธีทำใน WordPress (สำหรับบอส/ผู้ดูแลเว็บ)
**เมนู:** แดชบอร์ด WP → **Appearance → Menus** → เลือกเมนู (เช่น Main/Footer) → **Custom Link** → วาง URL + ข้อความลิงก์ → Save
**Footer/เนื้อหา:** หน้า Pages → แก้หน้า → เพิ่มบล็อก **Custom HTML** แล้ววาง:
```html
<p>ดูรายละเอียดเพิ่มเติม: <a href="https://knightbasins.srv1964473.hstgr.cloud/stone">แคตตาล็อกหินสังเคราะห์และราคา (Knight Basins)</a></p>
```
(ตรวจว่าในตัวแก้ไขไม่มีตัวเลือก “เปิดในแท็บใหม่ + nofollow” ถูกติ๊กไว้)

## 4) เดวิดจะตรวจให้ (หลังบอส/ผู้ดูแลเพิ่มลิงก์แล้ว)
1. ดึง HTML ของทั้งสองเว็บ → ตรวจว่ามี URL ของเรา **และไม่มี `rel="nofollow"`** (แนบผลจริง)
2. เฝ้าดูรายงาน 09:00 (index · แสดงผล · คลิก) + รายงาน `Links` ของ GSC (ใช้เวลาหลายวัน–สัปดาห์)
3. รายงานตรงกับบอสว่าลิงก์ถูกเก็บหรือยัง (ห้ามสรุปว่า “ได้ผลแล้ว” จนกว่าจะมีตัวเลข)

## 5) ถ้าบอสต้องการให้เดวิดทำเอง
ต้องใช้ช่องทางปลอดภัยแบบ **ไม่ส่งรหัส admin** เช่นสร้าง **WP Application Password** เฉพาะกิจให้ผู้ช่วย แล้วลบทิ้งหลังใช้ — **แต่ผมแนะนำให้ผู้ดูแลเว็บทำเอง** เพราะเป็นคนละระบบกับที่ผมดูแล และลดความเสี่ยงเรื่องรหัส
