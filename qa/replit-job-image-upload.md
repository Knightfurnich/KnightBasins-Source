# ใบงานส่ง Replit — ระบบอัปโหลดรูปภาพสินค้า (Image File Upload) & เซิร์ฟเวอร์ออก URL อัตโนมัติ

> 13 ก.ย. 2026 · ตามคำสั่งเจ้าของ: เปลี่ยนจากช่องกรอก URL เป็นปุ่มอัปโหลดไฟล์รูปภาพจริง (File Upload) โดยเซิร์ฟเวอร์ VPS เป็นผู้ออก URL คืนกลับมาให้อัตโนมัติ

---

## GOAL
ในฟอร์มแก้ไข/เพิ่มสินค้าหลังบ้าน (Admin Workbench) ทีมงานไม่ต้องก๊อป URL มาวางเอง แต่สามารถกดปุ่ม **"เลือกไฟล์ / อัปโหลดรูปภาพ"** แล้วเซิร์ฟเวอร์ VPS จะเซฟไฟล์และสร้าง URL ให้โดยอัตโนมัติ

---

## สิ่งที่ต้องทำ

### 1. ปรับฟอร์มหลังบ้าน (Frontend Admin Form)
- เปลี่ยนช่อง `URL รูปสินค้า` ให้เป็น **ปุ่มอัปโหลดไฟล์ (File Upload Button / Input File)** 
- แสดงรูปภาพตัวอย่าง (Image Preview) ทันทีที่ทีมงานเลือกไฟล์
- หากมีรูปภาพเดิมอยู่แล้ว ให้แสดงรูปเดิม พร้อมปุ่ม "เปลี่ยนรูปภาพใหม่"

### 2. สร้าง API สำหรับรับไฟล์อัปโหลดฝั่ง Server (`POST /api/admin/upload`)
- สร้าง Endpoint รับไฟล์รูปภาพ (`multipart/form-data`) สำหรับแอดมิน
- เซฟไฟล์ลงโฟลเดอร์เซิร์ฟเวอร์ VPS (เช่น `/usr/share/nginx/html/kb/images/uploads/` หรือ Storage ของแอป)
- คืนค่า URL สมบูรณ์กลับมาให้อัตโนมัติ เช่น `https://api.srv1964473.hstgr.cloud/kb/images/uploads/filename.png?v=<timestamp>`
- นำ URL ที่เซิร์ฟเวอร์ส่งกลับมาไปบันทึกลงฐานข้อมูลสินค้าให้อัตโนมัติ

---

## เกณฑ์ตรวจรับ (แนบหลักฐานจริง)
```
1. หน้าแอดมินมีปุ่มกดเลือกไฟล์รูปภาพจากเครื่องคอมพิวเตอร์/มือถือ (แนบภาพ)
2. เมื่ออัปโหลดไฟล์สำเร็จ -> แสดงรูป Preview และเซิร์ฟเวอร์คืนค่า URL คืนให้อัตโนมัติ (แนบภาพ)
3. รูปที่อัปโหลดใหม่ แสดงผลบนหน้าร้านได้ถูกต้องปกติ (แนบภาพ)
```

## ⛔ ข้อห้าม
- ห้ามแตะ Auth / Session
- ห้ามให้ผู้ใช้งานที่ไม่ใช่แอดมินใช้อัปโหลดไฟล์ได้ (ต้องมี Admin Guard)
