## ผลตรวจ (หลักฐานจริง)

### ✅ ส่วนที่ปกติ — ห้ามแก้
- ไฟล์รูปบนเซิร์ฟเวอร์ครบ: `swatch` 86 · `slab` 84 · `basin` 31 · ยิงได้ `HTTP 200 image/png` ทุกไฟล์
- หมวด **อ่างล้างจาน**: 30 การ์ด รูปขึ้นครบ (ตรงกับที่เจ้าของเห็น)
- หน้าออกแบบ: ชีตสี 71 แถวมีรูป · ชีตอ่าง 30 แถวมีรูป

### ❌ บั๊ก 1 (ตัวจริง) — ตัวโหลดรูปแบบ lazy หา container ไม่เจอ
`artifacts/knightdesign-web/src/components/catalogue-image-viewer.tsx` บรรทัด 34
```ts
const scrollRoot = node.closest('[data-testid^="list-catalogue-"]');
```
- หน้าออกแบบใช้ `list-catalogue-colours` / `list-catalogue-basins` → **ตรง**
- workbench ใหม่ (หน้า /catalogue) ใช้ `list-support-catalogue-<category>` → **ไม่ตรง** (`list-support-` ≠ `list-catalogue-`)
- ผล: `closest()` คืน `null` → observer ผูกกับ viewport แทนกล่องที่เลื่อนอยู่

**หลักฐานที่วัดได้:**
```
หมวดสี + เลือกวัสดุ veined  -> 35 การ์ด · มีแท็ก <img> 35 · โหลดได้ 0 · src ว่าง 35
หมวดสี + เลือกวัสดุ speckled -> 29 การ์ด · มีแท็ก <img> 29 · โหลดได้ 0 · src ว่าง 29
หลังเลื่อนการ์ดเข้าวิว        -> เริ่มโหลด (16/29 ได้ src + naturalWidth 360)
หมวดอ่าง                     -> โหลดครบ 30
```

### ❌ บั๊ก 2 — การ์ด "วัสดุหลัก" ไม่มีรูปเลย
`support-catalogue-workbench.tsx` ฟังก์ชัน `options` — `materialOptions` **ไม่มีฟิลด์ `imageUrl`** (ขณะที่ `colourMap` และ `sinkOptions` มี)
**หลักฐาน:** ขั้น 1 "เลือกวัสดุหลัก" การ์ด 4 ใบ (white_plain / other_plain / speckled / veined) → แท็ก img ที่มี src = **0 ใบ**

### ❌ บั๊ก 3 — deep link `?category=colour` แสดงลิสต์ว่าง
เปิด `/catalogue?category=colour` โดยยังไม่เลือกวัสดุ → การ์ด 0 ใบ (ควรขึ้นข้อความแนะนำให้เลือกวัสดุก่อน ไม่ใช่ลิสต์ว่าง)

### ⚠️ ข้อสังเกตข้อมูล (ฝั่งเรา — เดวิดจะจัดการเอง ไม่ต้องแก้ในโค้ด)
`pricing.public.json` มีรหัสสี 52 จาก 74 รายการที่ **มีเว้นวรรค** เช่น `"MU 010"` ขณะที่ UI แสดง `MU010`
→ ต้องเทียบรหัสแบบ normalize (ตัดช่องว่าง + case-insensitive) อยู่แล้ว ห้ามลบ/เปลี่ยนรหัสจริงในแคตตาล็อก

## สิ่งที่ต้องแก้ (Replit)

1. **`catalogue-image-viewer.tsx`** — ให้หา scroll container ได้ทั้งสองแบบ
   ```ts
   const scrollRoot = node.closest('[data-testid^="list-catalogue-"], [data-testid^="list-support-catalogue-"]');
   ```
   และถ้าหาไม่เจอ ให้ตั้ง `shouldLoad = true` ทันที (ห้ามค้างที่ src ว่าง)
2. **การ์ดวัสดุหลัก** — ใส่ `imageUrl` ให้ `materialOptions` = รูปของสีแรกใน tier (`imageUrl ?? slabImageUrl`) และคง `fallbackLabel` 2 ตัวอักษรเมื่อไม่มีรูป
3. **โหลดรูปชุดแรกแบบ eager** — การ์ดที่มองเห็นตอนเปิดหน้า (เช่น 12-24 ใบแรก) ให้โหลดทันที ไม่ต้องรอ intersection
   เพื่อไม่ให้ผู้ใช้เห็นช่องเปล่า/ตัวอักษรย่อแทนรูปตอนเปิดหน้า
4. **เพิ่มสถานะระหว่างโหลด** — ช่องรูปควรมี skeleton/spinner ชัดเจน ไม่ใช่พื้นเทาเปล่า
5. **deep link `?category=colour`** — แสดงข้อความ "เลือกวัสดุหลักก่อน" แทนลิสต์ว่าง

## เกณฑ์ตรวจรับ (แนบหลักฐานจริง)
```
1. /catalogue หมวดสี + เลือกวัสดุ (speckled และ veined) -> การ์ดสีมีรูปขึ้นโดยไม่ต้องเลื่อน (แนบภาพ)
2. ค่า naturalWidth > 0 ของการ์ดสี อย่างน้อย 12 ใบแรก (แนบตัวเลข)
3. การ์ดวัสดุหลัก 4 ใบมีรูป (แนบภาพ)
4. /catalogue?category=colour (ยังไม่เลือกวัสดุ) -> มีข้อความแนะนำ ไม่ใช่ลิสต์ว่าง (แนบภาพ)
5. หมวดอ่างล้างจานต้องยังเหมือนเดิม (30 การ์ดมีรูป) · หน้าออกแบบรูปยังครบ
6. ไม่มี Regression: ราคา/การเลือกสี/การนำไปออกแบบ ยังทำงานเหมือนเดิม
```
