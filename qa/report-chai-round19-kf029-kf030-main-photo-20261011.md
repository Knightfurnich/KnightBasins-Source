## สรุป 5 บรรทัด
1. **แก้อะไร:** `GET /api/catalog` ส่งภาพหลักของ KF029 และ KF030 เป็น `/kb/images/basin-hd/<SKU>.jpg` แทนภาพฉากห้อง (โชว์รูม / สวน) โดยไม่แตะ DB และไม่ครอปภาพ — สลับเฉพาะเมื่อแถวใน DB ยังถือไฟล์ฉากห้องเดิมเป๊ะ ถ้าแอดมินอัปโหลดภาพใหม่ ภาพใหม่ชนะ
2. **เทสต์:** api-server 1290 / ผ่าน 1285 / ตก 5 (ชุดเดิม Windows: slip digest / support-guest) · `catalog-media.test.ts` 12/12 (ใหม่ 4 ข้อ) · ฝั่ง web ไม่ได้แตะไฟล์ใดเลย
3. **ตรวจไม่ได้:** ผลบน production หลัง deploy · ภาพ HD ของ KF029/KF030 มีบรรทัดข้อความขนาดติดใต้ภาพ (ตามที่เดวิดสั่ง "ไม่ครอป" จึงส่งไฟล์ตามเดิม) ผมยังไม่ได้ดูว่าบนการ์ดจริงแสดงผลดีหรือไม่
4. **ความเสี่ยง:** ผูกกับชื่อไฟล์อัปโหลดเดิมสองไฟล์ ถ้าบอสอัปโหลดไฟล์เดิมซ้ำจะถูกสลับเป็น HD (ตั้งใจ) · หน้าแอดมินที่ใช้ `withBasinMedia` จะเห็นภาพ HD ด้วย · ภาพฉากห้องยังอยู่ใน DB จนกว่าบอสเปลี่ยนเอง (ใบ 445-C ย้ายข้อมูลเข้า DB ในโอกาสถัดไปได้)
5. **ข้อเสนอ:** ให้บอสดูการ์ด KF029/KF030 หลัง deploy ว่าข้อความขนาดใต้ภาพรับได้หรือไม่ · KF025/KF028 ยังรอบอสยืนยัน (ภาพหลักเป็นฉากห้อง)
