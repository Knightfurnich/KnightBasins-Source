# ใบงานส่ง Replit — แนบรูป Mockup ชิ้นงานและรูปสินค้าลงในใบเสนอราคา (Visual Quotation Snapshot)

> ตามคำสั่งเจ้าของ (13 ก.ย. 2026): เพิ่ม Visual Quotation Snapshot ให้ใบเสนอราคาแสดงภาพ Canvas 2D Mockup และภาพสินค้าจริง

---

## GOAL
เมื่อกด "ออกใบเสนอราคา" หรือกด "พิมพ์/บันทึก PDF" ใบเสนอราคาต้องมี **ภาพ Mockup ของแบบเคาน์เตอร์ (Canvas Rendering) และภาพตัวอย่างสินค้าจริง** แนบอยู่ในเอกสาร เพื่อให้ลูกค้าเห็นภาพรวมก่อนอนุมัติสั่งซื้อ

---

## สิ่งที่ต้องทำ

### 1. บันทึกภาพ Canvas Mockup ลงใน Snapshot (`calculation_snapshots`)
- เมื่อระบบคำนวณราคาและบันทึก Snapshot หรือเมื่อกดออกใบเสนอราคา ให้จับภาพ (Data URL / Image Snapshot) ของผืน Canvas 2D (ชิ้นงาน + ตำแหน่งช่องเจาะอ่าง)
- บันทึก Data URL / Image URL นี้ลงในฟิลด์ `designSnapshotUrl` หรือ `mockupImageUrl` ของ Snapshot ฝั่ง Server

### 2. แสดงผลภาพ Visual ในหน้า `/quote/:id` และใบพิมพ์ (Print/PDF Output)
- ในใบเสนอราคา (ทั้งบนจอและตอนพิมพ์ `@media print`):
  - **ส่วนแสดงแบบ:** เพิ่มกล่อง **"ภาพจำลองแบบเคาน์เตอร์ (2D Countertop Preview)"** แสดงภาพ Canvas Mockup ชิ้นงานจริงพร้อมระบุขนาดและตำแหน่งเจาะอ่าง
  - **ส่วนแสดงรายการสินค้า:** แต่ละรายการในตาราง (สีหินสังเคราะห์, รุ่นอ่างล้างหน้า) ให้มีรูป Thumbnail ของสี/อ่าง ประกอบอยู่ข้างชื่อรายการ
- รูปภาพทั้งหมดในใบเสนอราคาต้องอ่านจาก Snapshot ที่ Freeze ไว้แล้ว (ไม่ดึงสดเพื่อป้องกันภาพเปลี่ยนในภายหลัง)

---

## เกณฑ์ตรวจรับ (แนบหลักฐานจริง)
```
1. เมื่อออกใบเสนอราคา -> มีการบันทึกภาพ Mockup ของ Canvas ลงใน Snapshot (แนบข้อมูล Snapshot จาก DB/API)
2. บนหน้า /quote/:id และตอนกดพิมพ์ -> มีกล่องภาพจำลองแบบเคาน์เตอร์ 2D แสดงอยู่อย่างชัดเจน (แนบภาพ)
3. ตารางรายการสินค้าในใบเสนอราคา มีรูปภาพสีหินและรูปอ่างประกอบทุกรายการ (แนบภาพ)
4. เมื่อกดพิมพ์เป็น PDF -> ภาพ Mockup และภาพสินค้าแสดงผลชัดเจน ไม่ขาด/ไม่เบี้ยว (แนบภาพ PDF)
```
