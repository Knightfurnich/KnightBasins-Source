# รายงาน 457-C — JSON-LD ของ "เสาวางของตั้งพื้น" ไม่ถูกเรียกเป็นอ่างล้างหน้าอีก

**ผู้ทำ:** เดวิด (งานนี้บอสสั่งให้ทำเอง: "ทำได้เลยมั้ย") · **วันที่:** 11 ต.ค. 69 · **ที่มา:** ข้อค้นพบของรีพิต ใบ 451-R (เดวิดวัดซ้ำเองแล้วยังจริง)
**สถานะ:** ✅ code + test + two-way proof ครบ · ⚠️ **รอตรวจอิสระจากชัยตามกติกา "งานที่เดวิดทำเองต้องมีคนตรวจซ้ำ"**

## แก้อะไร
`artifacts/knight-basins/src/data/structured-data.ts` — `buildBasinProductsJsonLd()` เดิมประกอบคำบรรยายแบบตายตัวว่า
`อ่างล้างหน้าหินสังเคราะห์ … ขนาดเคาน์เตอร์ …` ให้ **ทุกแถว** ⇒ KF029/KF030 (ที่ API ส่ง `category: "storage"`) ถูกโฆษณาเป็นอ่างล้างหน้าให้ search engine/AI

แก้เป็น: คำบรรยายสร้างจาก **ประเภทของแถวนั้น** (`category` + `categoryLabel`) — ไม่มีคำที่พิมพ์เองในโค้ด
