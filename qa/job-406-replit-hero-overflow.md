```
artifacts/knight-basins/src/index.css:962
.catalog-hero::before, .stone-hero::before, .quote-heading::before {
  content: ""; position: absolute; inset: 0 -20vw; z-index: -1;
  background: linear-gradient(115deg, rgba(228,244,252,.88), rgba(244,249,253,0) 58%);
  pointer-events: none; }
```

- `inset: 0 -20vw` ⇒ pseudo-element กว้างเกินกล่อง **±20vw** (ที่ 1280 px = ±256 px ⇒ รวม 1649 px)
- ตัวมันไม่มี `overflow: clip` ที่ตัวแม่ ⇒ เข้าไปกองอยู่ใน **scrollable overflow ของ `documentElement`**
- **พิสูจน์ด้วยการซ่อนทีละส่วน:** ซ่อน `.stone-hero` → `scrollWidth` ลดจาก 1457 → 1265 (สะอาด) = ตัวการเดียว
- `/price-guide` ไม่มี pseudo ตัวนี้ ⇒ **0 px** (ใช้เป็นตัวเทียบได้)
