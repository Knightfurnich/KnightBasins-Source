# ใบงานส่ง Replit — แนบวิดีโอ 3D และ QR Code ในใบเสนอราคา (Video-Enabled Quotation)

> 13 ก.ย. 2026 · ต่อจากงานสร้างวิดีโอ 3D อ่างล้างหน้าทั้ง 30 รุ่นสำเร็จครบถ้วน

---

## GOAL
ใบเสนอราคา (หน้า `/quote/:id` และใบพิมพ์/PDF) ต้องมี **คลิปวิดีโอ 3D หมุน 360° ของอ่างล้างหน้า** และ **QR Code สำหรับสแกนดูวิดีโอ 3D บนเอกสารพิมพ์** เพื่อให้ลูกค้าเห็นมิติสินค้าชัดเจนที่สุดก่อนตัดสินใจซื้อ

---

## สิ่งที่ต้องทำ

### 1. หน้า `/quote/:id` บนจอ (Interactive Web View)
- ในตารางรายการสินค้า และกล่องรายละเอียดอ่างล้างหน้า:
  - หากรายการนั้นมี `videoUrl` ให้แสดง **เล่นคลิปวิดีโอ 3D หมุน 360°** (Autoplay, Muted, Loop, Playsinline) หรือปุ่มกดเล่นวิดีโอ 3D ข้างรูปถ่ายนิ่ง
  - ลูกค้าสามารถกดดูวิดีโอ 3D ของอ่างล้างหน้าได้โดยตรงจากหน้าใบเสนอราคาระหว่างพิจารณาตัดสินใจ

### 2. ใบเสนอราคาฉบับพิมพ์/บันทึก PDF (`@media print`)
- เนื่องจากกระดาษพิมพ์/ไฟล์ PDF ไม่สามารถเล่นวิดีโอได้โดยตรง:
  - ในส่วนตารางรายการอ่างล้างหน้า ให้แสดง **ภาพ Snapshot 3D จากวิดีโอ** พร้อมแนบ **QR Code สแกนดูวิดีโอ 3D 360°** ควบคู่กัน
  - เมื่อลูกค้า/ผู้รับใบเสนอราคานำมือถือมาสแกน QR Code บนกระดาษ จะเปิดดูคลิปวิดีโอ 3D หมุน 360° ของอ่างรุ่นนั้นได้ทันที!

### 3. บันทึกลิงก์วิดีโอลงใน Snapshot (`calculation_snapshots`)
- เมื่อกดออกใบเสนอราคา ลิงก์ `videoUrl` ของอ่างรุ่นนั้นๆ ต้องถูกบันทึกลงใน Snapshot ฝั่ง Server เพื่อให้เอกสารฉบับพิมพ์และย้อนหลังดึงลิงก์เดิมมาแสดงเสมอ

---

## เกณฑ์ตรวจรับ (แนบหลักฐานจริง)
```
1. บนหน้า /quote/:id -> รายการอ่างมีวิดีโอ 3D หมุน 360° แสดงผลและเล่นได้ (แนบภาพ)
2. เมื่อกดพิมพ์ใบเสนอราคาเป็น PDF -> ตารางอ่างมี QR Code สำหรับสแกนดูวิดีโอ 3D 360° แนบอยู่อย่างชัดเจน (แนบภาพ PDF)
3. สแกน QR Code จากเอกสาร PDF -> ลิงก์ตรงไปเปิดไฟล์วิดีโอ 3D ของอ่างรุ่นนั้นๆ ได้ถูกต้อง (แนบหลักฐาน)
```
