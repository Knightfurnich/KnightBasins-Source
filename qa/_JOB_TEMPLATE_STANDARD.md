# แม่แบบใบงานมาตรฐาน (เดวิด)

**แม่แบบมาตรฐาน (แก้ตามรายงานชัย 11 ต.ค. 69 — ใช้ทุกใบต่อจากนี้):**
1. **baseline เทสต์ต้องระบุ commit + OS + ผู้รัน + คำสั่ง** — ห้ามใส่ตัวเลขลอย (ของเดิม web 1,289/1,247 เป็นของ Linux/เดวิด; เครื่องชัย Windows ได้ 1,297/1,243) ⇒ ให้รันเองแล้วรายงานของตัวเอง
2. **ช่องทางส่งรายงาน:** วางไฟล์รายงานในรีโปที่ `qa/` ผ่าน **PR** (เครื่องผู้รับงานเข้า `/opt/data` ไม่ได้) · ชื่อไฟล์ `qa/report-<ผู้ทำ>-round<N>-<หัวข้อ>-<วันที่>.md`
3. **ตัวอย่าง curl ต้องใช้ชื่อฟิลด์จริงของฟีด** — ฟีดอ่างไม่มีฟิลด์ `name`; ใช้ `sku` · `color` · `colorName` · `imageUrl` · `basinDimensions` · `bowlShape` · `bowlShapeLabel` · `bowlOverflowHole`
4. **ห้ามแตะ** `api-server/**` (ชัย) · `src/data/**` (ชัย) · `src/components/**` · `src/admin/**` (บอย) ตามเจ้าของไฟล์
5. **พิสูจน์สองทาง:** ถอดการแก้ → เทสต์ต้องตก · คืน → ต้องผ่าน ครบทั้งสองด้าน

อัปเดต: 11 ต.ค. 69 (ตามข้อปรับของชัยในรายงานสรุป 436-C/KF003/438-C)
