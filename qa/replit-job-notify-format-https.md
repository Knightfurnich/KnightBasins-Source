## งาน 1 (บั๊ก): ลิงก์ในข้อความแจ้งเตือนต้องเป็น https
ปัจจุบันข้อความที่ส่งเข้ากลุ่มขึ้นต้น `http://knightbasins.srv1964473.hstgr.cloud/...`
สาเหตุ: `requestOrigin()` ใน `artifacts/api-server/src/routes/leads.ts` อ่าน `x-forwarded-proto`
แต่เส้นทางจริงคือ traefik (TLS) → nginx ในคอนเทนเนอร์เว็บ → API ทำให้ฝั่ง API เห็นค่าเป็น `http`

แก้: ให้ลิงก์ที่ส่งออกเป็น https เสมอเมื่ออยู่ production
- ใช้ค่าจาก env ก่อน (เพิ่ม `PUBLIC_APP_ORIGIN=https://knightbasins.srv1964473.hstgr.cloud`)
- ถ้าไม่มี env ค่อย fallback ไปอ่าน header
- หรือบังคับ https เมื่อ `NODE_ENV=production`

## งาน 2: ปรับรูปแบบข้อความให้สั้นและอ่านง่าย
ปัจจุบันรายการยาวหลายบรรทัดต่อ 1 รายการ เช่น
`KF002 x3 ชุด Soft · อ่างวางเคาน์เตอร์ · 600 × 800 × 200 mm · หลุม 350 × 500 × 130 mm`

เปลี่ยนเป็นสั้น กระชับ:
```
Knight Basins: ใบเสนอราคาใหม่
เลขที่: Sep 26 / US / 179254
ผู้ติดต่อ: คุณสมชาย · โครงการ: บ้านสุขุมวิท
โทร: 08x-xxx-xxxx

รายการ:
- KF002 Soft ×3 ชุด
- หิน SG420 Sanded Grey 1.26 ตร.ม.   (แสดงเฉพาะเมื่อมีข้อมูลสีหิน)

ยอดก่อน VAT: 57,000 บาท
VAT 7%: 3,990 บาท
ยอดรวมสุทธิ: 60,990 บาท
ลิงก์: https://knightbasins.srv1964473.hstgr.cloud/quote/view?quote=...
```
- รายการอ่าง: ใช้แค่ `รหัส + ชื่อสี ×จำนวน หน่วย` ห้ามใส่สเปกขนาด/หลุมในข้อความ (ทีมขายกดลิงก์ไปดูได้)
- ยอดเงินต้องแยกให้ชัดว่าอันไหนก่อน VAT อันไหนรวม VAT แล้ว — ถ้าใบนั้นไม่ได้คิด VAT ให้แสดง "ยอดรวม (ยังไม่รวม VAT)"
- สีหิน: แสดงเมื่อ payload มีข้อมูลจริงเท่านั้น **ถ้าไม่มีให้ข้าม ห้ามเดา**
- ใช้รูปแบบเดียวกันกับข้อความของโหมดแนบรูปวาดมือ (คำบรรยายใต้รูป) ให้สั้นแบบเดียวกัน

## เกณฑ์ตรวจรับ (แนบหลักฐานจริง)
1. ส่งแจ้งเตือนจากหน้าใบเสนอราคา → ลิงก์ในข้อความขึ้นต้น `https://` (แนบภาพข้อความในกลุ่ม)
2. ข้อความมีรายการแบบสั้น `รหัส ชื่อ ×จำนวน หน่วย` ไม่มีสเปกขนาด/หลุม (แนบภาพ)
3. แสดงยอดแยก: ก่อน VAT / VAT / รวมสุทธิ ตัวเลขตรงกับใบเสนอราคา (แนบภาพ)
4. ใบที่ไม่ได้คิด VAT → แสดง "ยังไม่รวม VAT" ไม่โชว์บรรทัด VAT (แนบภาพ)
5. ถ้ามีข้อมูลสีหิน → แสดงบรรทัดหิน · ถ้าไม่มี → ไม่มีบรรทัดนั้นและไม่ error (แนบภาพ)
6. โหมดแนบรูปวาดมือ → คำบรรยายสั้นแบบเดียวกัน และรูปยังส่งได้ (แนบภาพ)
