# ใบงานส่ง Replit — ปรับปรุง UI แผงน้องไนท์ (KnightSupport Panel)

> ตามคำสั่งเจ้าของ (13 ก.ย. 2026): ปรับการแสดงผลแผงน้องไนท์ และปรับรูปแบบการแชทให้เป็น Timeline ย้อนหลังได้

---

## 1. การปรับขนาดพื้นที่ตรงกลาง (Auto-resize Workspace)
- **ปัจจุบัน:** เมื่อเปิดแผงน้องไนท์ (KnightSupport) บน Desktop แผงด้านขวาจะดันหรือทับพื้นที่ทำงานตรงกลาง (Plan Studio / Canvas)
- **สิ่งที่ต้องทำ:** เมื่อเปิด/ปิดแผงน้องไนท์ ให้พื้นที่ทำงานตรงกลาง (Workspace / Plan Studio) **ปรับขนาดความกว้าง (Auto-resize/Responsive) อัตโนมัติ** ให้พอดีกับพื้นที่ที่เหลืออยู่ โดยไม่โดนแผงน้องไนท์บัง และไม่ทำให้องค์ประกอบภายในพื้นที่ตรงกลางเบี้ยวหรือเรียงตัวผิดปกติ

## 2. รูปแบบการแชทและการดูประวัติย้อนหลัง (Chat Timeline History)
- **ปัจจุบัน:** หน้าถามตอบ KnightSupport เป็นแบบถาม-ตอบ หรือแผงโต้ตอบ
- **สิ่งที่ต้องทำ:** 
  1. ปรับรูปแบบ UI ให้เป็น **Chat Timeline (เหมือน LINE / Telegram)** ที่มีฝั่งข้อความผู้ใช้ (User) และฝั่งตอบกลับของน้องไนท์ (Assistant) ชัดเจน
  2. **ดูประวัติข้อความย้อนหลังได้:** เมื่อเปิดแผงน้องไนท์ใน session เดิม ต้องดึงประวัติการสนทนาเก่า (Chat History) มาแสดงย้อนหลังได้ ไม่หายเมื่อสลับหน้าหรือเปิด/ปิดแผง
  3. มี Scrollbar ให้เลื่อนดูข้อความเก่าๆ ด้านบน และเมื่อมีข้อความใหม่เข้ามาให้ Auto-scroll ลงล่างสุด

---

## เกณฑ์ตรวจรับ
```
1. เปิดแผงน้องไนท์บน Desktop -> พื้นที่ตรงกลาง (Plan Studio) ปรับความกว้างพอดีอัตโนมัติ ไม่โดนบัง และไม่แตกแนวตั้ง (แนบภาพ)
2. แชทเป็นรูปแบบ Timeline สไตล์ LINE / Telegram (กล่องข้อความซ้าย-ขวา ชัดเจน) (แนบภาพ)
3. ปิดแผงแล้วเปิดใหม่ หรือสลับหน้า -> ประวัติข้อความเดิมยังอยู่ สามารถเลื่อนดูย้อนหลังได้ (แนบภาพ)
```

## ⛔ ข้อห้าม
- ห้ามแตะ Auth / Session
- ห้ามเปลี่ยน Persona น้องไนท์ (ใช้ ค่ะ/คะ)
- ห้ามส่งคำถามไปหา Hermes โดยตรงผ่าน Frontend (ต้องผ่าน API Server เท่านั้น)
