## 🔍 เช็คลิสต์ 3 หน้าจอที่ Replit ต้องลงมือสแกนอย่างละเอียด

### 1️⃣ หน้า 2D Studio Configurator (`/studio`)
- [ ] ปุ่ม "ดูลายแผ่นจริง" (`button-studio-active-stone-slab-open`): ปรากฏเฉพาะเมื่อหินมี `slabImageUrl` หรือไม่? ถ้าไม่มี ต้องซ่อนสนิท 100%
- [ ] การเปิด Modal ดูภาพเต็มแผ่น: รูปขนาดใหญ่โหลดคมชัด มีปุ่มปิดชัดเจน กด Esc หรือคลิกพื้นหลังแล้วปิดได้ปกติหรือไม่
- [ ] การสลับชนิดหิน / หินสังเคราะห์: ราคาและพื้นที่ (ตร.ม.) คำนวณถูกต้องตามเรตราคาหรือไม่ มี NaN หรือเลขอินฟินิตี้หลุดออกมาหรือไม่
- [ ] การขอใบเสนอราคาจาก Studio: ฟิลด์ `imageUrl` ของหินถูกส่งแนบไปใน payload หรือไม่

### 2️⃣ หน้าเลือกซื้อและเปรียบเทียบหิน (`/stone`)
- [ ] ปุ่ม "ดูภาพเต็มแผ่น" บนการ์ดหิน (`button-stone-slab-open`): แสดงถูกต้องเฉพาะหินที่มีภาพหรือไม่
- [ ] โหมดมืดและโหมดสว่าง (Dark / Light Theme): สีตัวหนังสือ คอนทราสต์ และขอบภาพ อ่านง่าย ไม่จมในพื้นหลัง
- [ ] การค้นหารหัสสีหิน (Search filter): ค้นหาแบบตัวพิมพ์เล็ก-ใหญ่ (Case-insensitive) ทำงานถูกต้องและรวดเร็วหรือไม่
- [ ] ตะกร้าสินค้าและการขอใบเสนอราคาด่วน: คำนวณยอดเงินถูกต้องหรือไม่

### 3️⃣ หน้าใบเสนอราคาอย่างเป็นทางการ (`/quote/view`)
- [ ] การแสดงภาพ Thumbnail หินในตาราง Description: ไม่ทับกับชื่อรหัสสินค้า และไม่ดันช่องราคาจนล้นตาราง
- [ ] Print Layout Preview (A4 PDF): เมื่อกด Print Preview (จำลองหน้ากระดาษ A4) ตารางแสดงพอดี ไม่ตกหน้า ไม่เบียด และไม่มี CSS พัง
- [ ] ความครบถ้วนของข้อมูลเอกสาร (ทั้งแบบ US และ OF): ข้อมูลบริษัท, เงื่อนไขการชำระเงิน, และดอกจันหมายเหตุแสดงถูกต้องครบถ้วน
