### ⚠ ทำไมแก้โค้ดแล้ว `/api/catalog` ยังพิมพ์ Glalet
`seedCatalogIfEmpty()` เติมข้อมูลเฉพาะตอนฐานข้อมูลว่าง (`onConflictDoNothing`) ชื่อที่ลูกค้าเห็นมาจากแถวใน DB ซึ่งแก้ได้ทางแอดมินเท่านั้น ผมไม่แตะฐานข้อมูล production (เป็นของเดวิด) จึงเสนอ 2 ทาง ให้เลือก:
- **ทาง 1 (ไม่เปลี่ยนโค้ด):** ให้บอสแก้ชื่อผ่านหน้าแอดมิน — 4 รหัส × 2 ตาราง + อ่าง KF015 KF018
- **ทาง 2 (ต้องอนุมัติ):** ผมเขียน migration ครั้งเดียวแบบ idempotent: `UPDATE … SET name='Galet …' WHERE code=… AND name='Glalet …'` (เปลี่ยนเฉพาะแถวที่ยังเป็นชื่อเก่าเป๊ะ) รันตอน deploy แล้วเทสต์ทั้งสองทาง — **ไม่ทำจนกว่าเดวิดสั่ง**

หลังชื่อใน DB เปลี่ยนแล้ว เดวิดต้องใส่ alias `Glalet Crystals / Glalet Ebony / Glalet Grey / Glalet Ice` ฝั่ง KB (`colour_aliases`) และ `stone-status.json` (ไฟล์ที่สคริปต์ของเดวิดสร้างจาก DB) จะอัปเดตเองเมื่อรันซ้ำ — ผมไม่แตะไฟล์นั้น

- **ความเสี่ยงคู่ขนาน:** หน้า `/price-guide` พิมพ์ค่างานกลางคืนจาก `INSTALLATION_PRICE` (ค่าติดตั้งชุดอ่าง ฿5,000) ไม่ใช่ค่าคงที่ของตัวเอง — ตอนนี้บังเอิญเท่ากับ `NIGHT_WORK_FEE` ถ้าบอสเปลี่ยนอย่างใดอย่างหนึ่ง หน้านั้นจะผิดโดยไม่มีใครรู้ เทสต์ที่ผมเพิ่ม (`assert.equal(NIGHT_WORK_FEE, INSTALLATION_PRICE)`) จะตกเตือน; ทางแก้จริงคือให้หน้านั้นใช้ `NIGHT_WORK_FEE` (ไฟล์ของ `/price-guide` ใบนี้ห้ามแตะ)
