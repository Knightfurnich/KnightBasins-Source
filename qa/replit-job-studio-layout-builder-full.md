# ใบงานส่ง Replit — ระบบสลับโหมดสั่งซื้อ, สตูดิโอวางแบบ 2D, และแนบรูปสเก็ตช์มือ (Studio Layout Builder & Order Modes)

> 14 ก.ย. 2026 · ใบงานฉบับละเอียดสมบูรณ์ กำหนดสถาปัตยกรรม UI/UX, กฎการคำนวณราคาหินและอ่าง, ระบบ Canvas 2D, และการแนบรูปสเก็ตช์หน้างาน

## 🎯 GOAL
พัฒนาหน้าออกแบบและสั่งซื้อ ให้รองรับพฤติกรรมลูกค้า 2 รูปแบบหลัก:
1. **ซื้อด่วน (Direct Quote Mode):** เลือกอ่าง + เลือกสีหิน ➔ ออกใบเสนอราคาได้ทันทีใน 1 นาที
2. **วางแบบเคาน์เตอร์ (Studio Layout Builder Mode):** มีถาดพักสินค้า (Shortlist Tray) รองรับสีหิน 2–3 สี และอ่าง 1–2 ใบ + เลือกทรงเคาน์เตอร์ (I / L / U) + กรอกขนาด กว้าง×ยาว (มม.) + ลากอ่างวางบน Canvas 2D + สลับดูสีหินและอ่างสดๆ พร้อมคำนวณราคา ตร.ม. และอ่างรายใบให้อัตโนมัติ
3. **แนบรูปสเก็ตช์หน้างาน (Sketch Upload Mode):** แนบรูปวาดมือ/รูปวัดหน้างานจริง สำหรับลูกค้าที่ไม่สะดวกวางแบบเอง ส่งข้อมูลให้ทีมขายผ่าน LINE

## 📐 SECTION 1 · ระบบโหมดการสั่งซื้อ (Order Modes & Switching)

### 1.1 แท็บสลับโหมดการสั่งซื้อ (Mode Switcher)
ที่ส่วนบนของหน้าออกแบบและแคตตาล็อก เพิ่มแท็บสลับโหมดชัดเจน:
- **[โหมด A: ซื้อด่วน / สั่งตามรายการ]** ➔ สำหรับลูกค้าที่รู้อยู่แล้วว่าต้องการอ่างรุ่นไหน หรือหินสังเคราะห์สีไหน
- **[โหมด B: จัดวางแบบเคาน์เตอร์ 2D]** ➔ เปิดสตูดิโอวางแบบเคาน์เตอร์
- **[โหมด C: แนบรูปวาดมือ / ให้ทีมงานออกแบบให้]** ➔ เปิดฟอร์มแนบรูปสเก็ตช์

## 🎨 SECTION 2 · สตูดิโอวางแบบเคาน์เตอร์ 2D (Studio Layout Builder Mode)

### 2.1 ถาดพักสินค้า (Shortlist Tray / Palette)
- มีถาดพักสินค้าด้านข้างหรือด้านล่าง ให้ลูกค้าเลือกรายการที่สนใจมาลองวางก่อน:
  - **หินสังเคราะห์:** เลือกรองรับได้ **2–3 สี** (เช่น BW010 สีขาว 7,500/ตร.ม. VS KZ802 สีเทาลายหินอ่อน 9,500/ตร.ม.)
  - **อ่างล้างหน้า:** เลือกรองรับได้ **1–2 รุ่น** (เช่น KF001 อ่างวางเคาน์เตอร์ VS KF020 อ่างตั้งพื้น)
- มีปุ่มสลับสีหินบน Canvas ได้ทันทีเมื่อกดเลือกสีใดสีหนึ่งในถาด ยอดราคารวม ตร.ม. บนหน้าจอต้องคำนวณเปลี่ยนตามเรตราคาของสีนั้นๆ ทันที

### 2.2 การเลือกทรงเคาน์เตอร์และกรอกขนาด (Countertop Geometry Inputs)
- เลือกรูปทรงเคาน์เตอร์มาตรฐาน 3 รูปแบบ:
  1. **I-Shape (เคาน์เตอร์แนวตรง):** กรอก ความยาว L1 (มม.) และ ความลึก D (มม.) [ค่าเริ่มต้น depth = 600 mm]
  2. **L-Shape (เคาน์เตอร์เข้ามุม L):** กรอก ความยาวฝั่ง A (มม.), ความยาวฝั่ง B (มม.) และ ความลึก D (มม.)
  3. **U-Shape (เคาน์เตอร์ล้อมสามด้าน U):** กรอก ความยาวฝั่ง A, B, C (มม.) และ ความลึก D (มม.)
- **บัวกันเปื้อนหลังเคาน์เตอร์ (Backsplash):**
  - มี Checkbox ติ๊กเลือก *"รับบัวกันเปื้อนหลังเคาน์เตอร์"* (กำหนดความสูงได้ เช่น 100 mm หรือ 120 mm)
  - นำพื้นที่บัวกันเปื้อน (ความยาวรวม × ความสูงบัว) ไปคิดรวมเป็นพื้นที่ ตร.ม. หินสังเคราะห์ด้วย

### 2.3 ผืน Canvas 2D แสดงแบบเสมือนจริง (Interactive 2D Canvas)
- วาดโครงสร้างเคาน์เตอร์สเกลจริงตามขนาดที่กรอก (92 px/เมตร)
- สามารถ **ลากอ่างล้างหน้า (Drag & Drop)** จากถาดพักสินค้ามาวางบนผืนเคาน์เตอร์
- ปรับตำแหน่งอ่างบนเคาน์เตอร์ได้ด้วยการลากเมาส์/นิ้ว หรือกรอกระยะห่างจากขอบ (มม.)
- **ระบบเตือนระยะเจาะอ่าง (Cutout Margin Safety Rule):**
  - ระยะห่างระหว่างขอบอ่างถึงขอบเคาน์เตอร์ทั้ง 4 ด้าน ต้องไม่น้อยกว่า **50 มม. (5 ซม.)**
  - หากลากอ่างชิดขอบเกิน 50 มม. ให้แสดงเส้นขอบเตือนสีแดง พร้อมข้อความ: *"ระยะเจาะชิดขอบเกินไป กรุณาเว้นขอบอย่างน้อย 5 ซม. เพื่อความแข็งแรง"*

## 💰 SECTION 3 · กฎการคำนวณราคาและข้อบังคับธุรกิจ (Business Pricing Rules)

### 3.1 การคิดราคาหินสังเคราะห์ (Solid Surface Pricing)
- คำนวณพื้นที่จริงจากรูปทรงเคาน์เตอร์:
  $$\text{พื้นที่หิน (ตร.ม.)} = \frac{\text{พื้นที่เคาน์เตอร์} + \text{พื้นที่บัวกันเปื้อน}}{1,000,000}$$
- **กฎการเจาะอ่าง (No Cutout Deduction):** การเจาะช่องวางอ่าง **ห้ามหักพื้นที่ช่องเจาะออก และห้ามบวกค่าเจาะเพิ่ม** (คิดพื้นที่เต็ม ตร.ม. ตามสเปค Knight Furnich)
- คิดราคาหินตามเรตสีที่เลือกในถาดพักสินค้า (7,500 / 8,500 / 9,500 บาท/ตร.ม.)

### 3.2 การคิดราคาอ่างล้างหน้า (Basin Pricing)
- คิดราคาตามจำนวนใบ (บาท/ชุด) ตามรุ่นอ่างที่ลากมาวางบน Canvas
- สั่งซื้ออ่างตั้งแต่ 3 ชุดขึ้นไป ➔ **ฟรีค่าดำเนินการติดตั้งอ่าง** (หากต่ำกว่า 3 ชุด คิดค่าติดตั้งอ่าง 5,000 บาท/ชุด)

### 3.3 การเช็กลิมิตขนาดแผ่นมาตรฐาน (0.76 × 3.60 ม.)
- ขนาดแผ่นหินมาตรฐานคือ **0.76 ม. (กว้าง) × 3.60 ม. (ยาว)**
- หากเคาน์เตอร์มีความลึกเกิน 0.76 ม. หรือความยาวเกิน 3.60 ม. ให้ขึ้นป้ายเตือน: *"ขนาดชิ้นงานเกิน 1 แผ่นมาตรฐาน จะมีรอยต่อหินสังเคราะห์เชื่อมเนียนประณีตไร้รอยต่อ (Seamless Joint)"*

### 3.4 ค่าดำเนินการตามสถานที่ติดตั้ง (Location & Minimum Area)
- มีช่องให้เลือกสถานที่ติดตั้ง:
  - **กทม. และปริมณฑล:** ขั้นต่ำ 1 ตร.ม. (หากพื้นที่รวมน้อยกว่า 5 ตร.ม. คิดค่าดำเนินการ 5,000 บาท, หากลูกค้ารับสินค้าเองไม่คิดค่าดำเนินการ)
  - **ต่างจังหวัด:** ขั้นต่ำ 3 ตร.ม. (หากพื้นที่รวมน้อยกว่า 10 ตร.ม. คิดค่าดำเนินการ 8,000 บาท)

## 📸 SECTION 4 · โหมดแนบรูปสเก็ตช์มือ (Sketch Upload Mode)

- สำหรับลูกค้าที่มีแบบวาดมือ/สเก็ตช์หน้างานจริง (เช่น รูปวาดขนาด L-Shape / I-Shape)
- มีฟอร์มให้ **แนบรูปภาพวาดมือ (Image/PDF Upload)** + เลือกสีหินที่สนใจ (2–3 สี) + เลือกรุ่นอ่างที่ชอบ (1–2 รุ่น)
- มีปุ่ม **"ส่งสเก็ตช์ให้ทีมขาย Knight Furnich ออกแบบและประเมินราคาให้"**
- ระบบยิงแจ้งเตือนรายละเอียดพร้อมรูปสเก็ตช์เข้า LINE ทีมงานทันที

## 📋 เกณฑ์ตรวจรับ (Verification Criteria)

```
1. หน้าออกแบบมีแท็บสลับ 3 โหมด (ซื้อด่วน / วางแบบ 2D / แนบรูปสเก็ตช์) (แนบภาพ)
2. ถาดพักสินค้าเลือกรองรับสีหิน 2-3 สี และอ่าง 1-2 รุ่น สลับสีบน Canvas แล้วราคารวม ตร.ม. เปลี่ยนทันที (แนบภาพ)
3. กรอกขนาด I / L / U + ติ๊กบัวกันเปื้อนหลังเคาน์เตอร์ นำพื้นที่ไปคิด ตร.ม. ถูกต้อง (แนบภาพ)
4. การเจาะอ่างไม่หักพื้นที่ ตร.ม. ออก และคิดราคาอ่างเป็นจำนวนใบถูกต้อง (แนบภาพ)
5. ลากอ่างชิดขอบเคาน์เตอร์น้อยกว่า 5 ซม. ขึ้นเส้นเตือนสีแดง (แนบภาพ)
6. เคาน์เตอร์ยาวเกิน 3.60 ม. หรือลึกเกิน 0.76 ม. ขึ้นเตือนเรื่องรอยต่อ Seamless Joint (แนบภาพ)
7. โหมดแนบรูปสเก็ตช์ สามารถอัปโหลดรูปวาดมือและส่งข้อมูลให้ทีมงานได้ถูกต้อง (แนบภาพ)
```
