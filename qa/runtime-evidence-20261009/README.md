# หลักฐานรันจริงจากเครื่อง Hermes — รอบ 9 ต.ค. 69

**ทำไมมีโฟลเดอร์นี้:** รีวิวอิสระ 2 ใบ (291 ของชัย · 292 ของ Qwen) ติดข้อจำกัดเดียวกัน —
สคริปต์และข้อมูลที่เดวิดอ้างถึง **อยู่ในเครื่อง Hermes เท่านั้น ไม่ได้อยู่ในรีโป** ผู้ตรวจจึงรันซ้ำไม่ได้
และต้องเขียนว่า "ตรวจไม่ได้" ทั้งที่ระบบอาจถูกต้อง 100% โฟลเดอร์นี้คือคำตอบ: **แนบผลรันดิบ + md5 ของสคริปต์ที่รัน**
เพื่อให้ครั้งต่อไปผู้ตรวจยืนยันได้เองโดยไม่ต้องมีสิทธิ์บนเครื่อง

## วิธีใช้ (สำหรับผู้ตรวจ)
1. เปิดไฟล์ที่ต้องการ → เห็นผลดิบพร้อมตัวเลข
2. เทียบ `checksums.md` กับสคริปต์ในเครื่อง (ถ้ามีสิทธิ์) หรือขอให้เดวิดรันซ้ำ — ผลต้องตรง
3. ถ้าต้องการรันเองแต่ไม่มีสิทธิ์บนเครื่อง Hermes: ระบุข้อที่ต้องการ ให้เดวิดรันและแนบผลในคอมเมนต์ PR

## ข้อจำกัดที่ยังเหลือ (พูดตรง ๆ)
- ผลรันเป็น **ภาพ ณ เวลาหนึ่ง** (ระบุในหัวไฟล์) ไม่ใช่หลักฐานสด — ของที่เปลี่ยนได้ (สถานะ index ของ GSC, จำนวนแถว DB) ต้องวัดใหม่ทุกครั้ง
- `ledger-summary.md` ไม่มีคอลัมน์ต้นทุน (ledger ไม่เก็บราคา) ⇒ คำนวณ "ประหยัดกี่บาท" จากไฟล์นี้ไม่ได้
- โฟลเดอร์นี้ **ไม่รวมตัวสคริปต์เอง** เพราะรีโปนี้เป็น public และสคริปต์ฝั่ง ops เปิดเผยพื้นผิวภายใน (ที่อยู่ VPS, ชื่อคอนเทนเนอร์, endpoint แอดมิน) — แนบ md5 + คำสั่งแทน ถ้าต้องการตัวสคริปต์ให้ขอผ่านช่องทางทีม
