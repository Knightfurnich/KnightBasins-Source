# ที่มาของตัวเลข `14,180 / 992.6 / 15,172.6` (ตอบรีวิว 302-Q ข้อ F-4)

**สรุปสั้น:** ตัวเลขชุดนี้ **ไม่ใช่ "ราคา SG420" และไม่ใช่ "เรต"** — เป็น **ผลคำนวณใบเสนอราคางานผลิต ของพื้นที่ 1.6682 ตร.ม.** จากเครื่องมือ `knight_price` (สูตรตายตัวในระบบ ไม่ได้คิดมือ)

## คำสั่งที่รันจริง (ทำซ้ำได้)
```
knight_price(sale_type="fabrication", colour_code="SG420", area_m2=1.6682, site="bkk", include_vat=true)
```

## ผลลัพธ์ (ตัดจากผลรันจริง)
```
rate_per_m2      = 8,500        (เรตกลุ่ม "สีมีเกล็ดต่างๆ")
material_subtotal = 14,179.7    → ปัดเป็น 14,180   ← 8,500 × 1.6682
vat (7%)          = 992.6
total             = 15,172.6
```

## ⚠️ ข้อควรรู้ที่ทำให้ "ตัวเลขไม่ครบ" ในอดีต
เครื่องมือเวอร์ชันปัจจุบันเพิ่มบรรทัด **"ค่าดำเนินการ กทม.+ปริมณฑล 5,000 (พื้นที่น้อยกว่า 5 ตร.ม.)"**
⇒ ยอดที่ครบถ้วนของงานนี้ = `19,179.7 + VAT = 20,522.28` (ไม่ใช่ 15,172.6)

**เพราะฉะนั้น:** เดวิด **ถอน** การเรียกชุดนี้ว่า "ราคา SG420 / 3 เรต" (ตามรีวิว 299-Q/302-Q) — ที่ถูกต้องคือ
- ราคา **แผ่น** SG420 = 9,000 / 8,800 / 8,550 บาท/แผ่น (จากแคตตาล็อก)
- **เรตงานผลิต** SG420 = 8,500 บาท/ตร.ม.
- และถ้าจะยกตัวอย่างใบเสนอราคา ต้องระบุ **พื้นที่ + ค่าดำเนินการ + VAT** ให้ครบทุกครั้ง
