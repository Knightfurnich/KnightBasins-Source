เงื่อนไข:
- รายการอ่าง = `รหัส + ชื่อสี ×จำนวน หน่วย` — **ห้ามใส่สเปกขนาด/หลุม**
- ยอดต้องแยก 3 บรรทัดตามตัวอย่าง · ถ้าใบนั้นไม่คิด VAT → แสดง `ยอดรวม (ยังไม่รวม VAT)` และไม่โชว์บรรทัด VAT
- สีหิน: แสดงเมื่อ payload มีข้อมูลจริง ถ้าไม่มีให้ข้าม ห้ามเดา
- ใช้รูปแบบเดียวกันกับคำบรรยายของโหมดแนบรูปวาดมือ

## งาน B: ข้อความเตือนตอนกดส่งในโหมด 2D ให้บอกสาเหตุจริง
ปัจจุบันเป็นข้อความกว้าง ๆ ว่า "กรุณาเลือกสินค้าและวางอ่างให้ครบก่อนส่งคำขอ"
แต่สาเหตุจริงพบบ่อยคือ "เลือกอ่างไว้หลายรุ่น แต่ยังวางอ่างบนผังไม่ครบทุกแบบ"
(ค่าเริ่มต้น ระบบเลือกอ่าง KF001 ไว้ให้ 1 รุ่น · ถ้าลูกค้าไปเลือก KF002 เพิ่มเป็น 2 รุ่น แต่วางเพียงตัวเดียว จะติดเงื่อนไขนี้)

แก้ให้แยกข้อความตามสาเหตุ:
- ยังไม่ได้วางอ่างเลย → `ยังไม่ได้วางอ่างบนผัง กรุณาลากอ่างที่เลือกไปวางบนผัง`
- เลือกไว้ N รุ่น วางแล้ว M ตัว (M < N) → `ยังวางอ่างไม่ครบทุกแบบที่เลือก (เลือก N รุ่น · วางแล้ว M ตัว) กรุณาลากอ่างที่เลือกวางบนผังให้ครบ`
- ระยะขอบไม่ผ่าน / ขนาดหลุมไม่ระบุ → คงข้อความเดิมที่มีอยู่แล้ว
- ยังไม่เลือกสีหิน / ขนาดเคาน์เตอร์ไม่ถูกต้อง → แจ้งสาเหตุนั้นให้ตรง

## เกณฑ์ตรวจรับ (แนบหลักฐานจริง)
1. ส่งแจ้งเตือนจากหน้าใบเสนอราคา → ข้อความในกลุ่มสั้นตามรูปแบบงาน A (แนบภาพ)
2. ยอดแยก ก่อน VAT / VAT / รวมสุทธิ ตรงกับใบเสนอราคา (แนบภาพ)
3. ใบที่ไม่คิด VAT → ขึ้น "ยังไม่รวม VAT" และไม่มีบรรทัด VAT (แนบภาพ)
4. โหมดแนบรูปวาดมือ → คำบรรยายสั้นแบบเดียวกัน รูปยังส่งได้ (แนบภาพ)
5. เลือกอ่าง 2 รุ่น วาง 1 ตัว → กดส่ง → ข้อความบอก "เลือก 2 รุ่น · วางแล้ว 1 ตัว" (แนบภาพ)
6. ยังไม่วางอ่างเลย → กดส่ง → ข้อความบอกให้ลากอ่างไปวาง (แนบภาพ)
7. เคสระยะขอบ/ขนาดหลุมไม่ระบุ → ข้อความเดิมยังทำงานถูกต้อง (แนบภาพ)
