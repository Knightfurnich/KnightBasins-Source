ในรอบการพัฒนาชุด **Task 209 ถึง Task 218** ทีมงาน (เดวิด, ชัย, Replit) สามารถส่งมอบฟีเจอร์หลักขึ้น Production สำเร็จทั้ง 10 งาน แต่จากการทบทวนโค้ดและระบบจริงอย่างละเอียด พบ **"ช่องโหว่และจุดตกหล่นสำคัญ 4 ด้าน"** ที่ต้องบันทึกไว้เพื่อวางแผนปรับปรุงอย่างเป็นระบบ:

## 🔴 1. ด้านความปลอดภัยและเงื่อนไขการค้า (Security & Business Logic Gaps)
1. **ช่องโหว่การบังคับใช้อายุลิงก์ 45 วัน (Job 213):**
   * **ตรวจพบ:** ปัจจุบันระบบเช็คอายุ 45 วัน (`isPublicQuoteTokenExpired`) เฉพาะ 3 เส้นทางคือ `GET /quotes`, `POST /promptpay-qr`, และ `POST /notify`
   * **จุดที่หลุด:** 
     * `POST /leads/payment-slip` (การอัปโหลดสลิปเงินมัดจำ/ยอดจบ) **ยังไม่มีการเช็คอายุลิงก์** ลูกค้าที่ถือลิงก์เก่าเกิน 45 วันยังสามารถส่งสลิปเข้ามาได้
     * `GET /public/track` (การติดตามสถานะงาน) **ยังไม่มีการเช็คอายุลิงก์**
   * **ผลกระทบ:** เสี่ยงต่อความถูกต้องทางการเงิน (ลูกค้านำลิงก์เก่าที่ราคาเปลี่ยนไปแล้วมาโอนเงิน)

---

## 🟡 2. ด้านระบบอัตโนมัติและการแจ้งเตือน (Automation & Operations Gaps)
1. **ระบบแจ้งเตือนเชิงรุกและสรุปสถิติประจำสัปดาห์ (Job 216-217 เฟส 2):**
   * **ตรวจพบ:** ยังไม่มีระบบ Cronjob เฝ้าระวังอัตโนมัติ (Automated Threshold Alert) เมื่อเกิดปัญหาสลิปซ้ำหรืออัปโหลดล้มเหลวติดต่อกัน
   * ยังไม่มีสคริปต์สรุปภาพรวม **Knight UX Digest ประจำสัปดาห์** ส่งเข้า Telegram บอสทุกเช้าวันจันทร์
2. **การล้างข้อมูลเก่า (Log Retention):**
   * ปัจจุบันปุ่ม Prune เป็นการกดด้วยมือของผู้ดูแลระบบ (Manual Trigger) ยังไม่มี Background Worker หรือ Cronjob ลบข้อมูลเกิน 90 วันให้อัตโนมัติ

---

## 🖼️ 3. ด้านคุณภาพข้อมูลและสื่อ (Catalog & Asset Gaps)
1. **ภาพสินค้าอ่าง 30 รุ่น (Job 212):**
   * รุ่น **KF029** และ **KF030** ในแคตตาล็อกต้นฉบับเป็นภาพแผ่นหินทั้งผืน (ไม่มีหลุมอ่าง) แม้ตัดพื้นหลังแล้ว ลูกค้าก็ยังมองไม่เห็นทรงอ่าง
   * ขนาดไฟล์ PNG ทั้ง 30 รุ่นรวมกันอยู่ที่ **13.7 MB** (เฉลี่ย 452 KB/ภาพ, สูงสุด 965 KB) ควรแปลงเป็น WebP เพื่อประหยัด Bandwidth มือถือของลูกค้า
2. **ภาพพื้นผิวหิน (Job 211):**
   * พบ 4 สีในแคตตาล็อกที่รูป `imageUrl` ยังไม่สมบูรณ์:
     * `MU010`: เป็นภาพผืนผ้าใบสีขาวที่มีเงาขอบ
     * `WH112`: มีแถบเงาสีเทาที่ขอบขวา
     * `NW013`: เป็นสีขาวล้วนไม่มีมิติ
     * `GC714`: มีลายน้ำตัวอักษรเล็กๆ ติดอยู่กลางภาพ

## ⚙️ 4. ด้านกระบวนการพัฒนาและโครงสร้างพื้นฐาน (DevOps & UX Gaps)
1. **Database Migrations บน VPS:**
   * ไฟล์ Migration (เช่น `020_*.sql` และ `021_*.sql`) ยังไม่ถูกสั่งรันอัตโนมัติใน GitHub Actions (`deploy.yml`) ต้องให้เดวิด SSH เข้าไปรันมือบน VPS ทุกครั้ง เสี่ยงต่อการลืมเมื่อมีการย้ายเซิร์ฟเวอร์
2. **การบังคับใช้กฎ Branch Protection บน GitHub:**
   * กฎ Ruleset บน GitHub Private Repo บัญชีบุคคลทั่วไปติดข้อจำกัดด้านนโยบายของ GitHub (Not enforced) ทำให้ยังต้องพึ่งพาการตรวจรับด้วยมือของเดวิดเป็นด่านสุดท้าย
3. **Studio 2D UX:**
   * แถบปุ่มตำแหน่งอ่าง 7 ระดับ ปัจจุบันคำนวณสแน็ปตามแกนยาวของแผ่นหลักเท่านั้น ยังไม่รองรับการสแน็ปตามแนวยาวของแผ่นขาแนวตั้ง (ชิ้นงานตัว L)
