## STEP 2 · หน้า `/quote/:id` (artifacts/knightdesign-web/src/pages/quote.tsx)

1. **เพิ่มปุ่ม "พิมพ์ / บันทึกเป็น PDF"** (`data-testid="button-print-quote"`)
   - เรียก `window.print()`
   - ใช้ CSS `@media print` จัดรูปแบบหน้ากระดาษ A4 ไม่ต้องลงไลบรารีเพิ่ม
2. **ช่องกรอกเลขที่เอกสาร** (`data-testid="input-document-number"`)
   - ทีมขายกรอกเอง เช่น `Sep 26 / US / 0754`
   - บันทึกไว้กับ draft (`quote.input.documentNumber`) และพิมพ์กลับมาตรง
   - ถ้ายังไม่กรอก ให้เว้นว่างในใบพิมพ์ (ห้ามสร้างเลขเอง)
3. **ราคายึดจากสิ่งที่ลูกค้าเลือก (3 แนวทาง) จาก `calculation_snapshots`**
   - ซื้อแผ่นดิบ -> บาท/แผ่น
   - งานผลิต+ติดตั้ง -> บาท/ตร.ม. (3 เรต: 7,500 / 8,500 / 9,500)
   - ชุดสำเร็จรูป (อ่าง) -> บาท/ชุด
   - ห้ามคำนวณราคาใหม่ และไม่มีการแยกค่าสินค้า/ค่าแรง
4. **รูปประกอบในใบเสนอราคา**
   - ดึงจาก `imageUrl` ของสีและอ่างที่ลูกค้าเลือกในระบบ
   - ถ้ารายการไหนไม่มีรูป ให้เว้นว่างไว้ ห้ามใส่รูปอื่นแทน
5. **โครงใบพิมพ์ (คัดจากใบจริง และ import จาก `KNIGHT_COMPANY_INFO`)**
   - หัวใบ: ชื่อบริษัท, เลขประจำตัวผู้เสียภาษี `0-1355-53014-11-4`, ที่อยู่, เบอร์โทร, อีเมล, (Quotation)
   - เลขที่เอกสาร + วันที่
   - ข้อมูลลูกค้า (ชื่อ/สาขา, ที่อยู่, เลขประจำตัวผู้เสียภาษี, โทร, ผู้ติดต่อ) + สถานที่ SITE
   - ตารางรายการ + รูปสินค้า + จำนวน + หน่วย + ราคา + รวมเงิน
   - สรุปยอด: รวมเงิน -> ส่วนลด -> หลังหักส่วนลด -> **ภาษีมูลค่าเพิ่ม 7%** -> **จำนวนเงินสุทธิ**
   - **จำนวนเงินเป็นตัวอักษรไทย** (แปลงจากยอดสุทธิ เช่น "สามหมื่นเจ็ดพันเก้าร้อยแปดสิบห้าบาทถ้วน")
   - รายละเอียดบัญชีธนาคารกรุงศรีอยุธยา เลขที่บัญชี `574-1-18925-4`
   - เงื่อนไขการชำระเงิน 50/50, ยอดไม่เกิน 40,000 ชำระ 100%, วางบิล Email/LINE เท่านั้น
   - กำหนดยืนราคา 30 วัน, เวลารับสินค้า, หมายเหตุค่าดำเนินการ
   - ผู้เสนอราคา + บรรทัด "ผู้มีอำนาจอนุมัติเสนอราคาขาย · ผู้มีอำนาจอนุมัติสั่งซื้อ และประทับตราบริษัท"
   - ถ้า `measurementStatus = estimated` แสดงคำเตือน: "ราคานี้อ้างอิงจากขนาดที่ลูกค้าแจ้ง ยังไม่ได้วัดหน้างานจริง ราคาอาจเปลี่ยนแปลงหลังการวัด"
6. **สิ่งที่ซ่อนตอนพิมพ์ (`@media print`)**
   - ซ่อน Navbar, ปุ่มแก้ไข (`link-edit-design`), ปุ่มแชท (`link-quote-support`), ปุ่มพิมพ์ (`button-print-quote`), อีเมลผู้ใช้งาน

## เกณฑ์ตรวจรับ (เดวิดตรวจซ้ำด้วยเบราว์เซอร์จริง)
```
1. artifacts/knightdesign-web/src/lib/company-info.ts มีอยู่จริงและข้อมูลตรงเป๊ะ
2. กด button-print-quote แล้วเรียก window.print()
3. เลขที่เอกสารที่กรอกใน input-document-number แสดงบนใบพิมพ์ถูกต้อง
4. หัวใบ, ที่อยู่, เลขผู้เสียภาษี 0-1355-53014-11-4, เลขบัญชี 574-1-18925-4 ถูกต้องถาวร
5. ยอดคำนวณและ VAT 7% ตรงกับ calculation_snapshots (เคสอ้างอิง 0.60x1.80 SG420 = 15,172.60 บาท)
6. ตัวอักษรไทยแปลงถูกต้อง
7. รูปสี/อ่างที่เลือกแสดงผลถูกต้อง
8. ตอนพิมพ์ไม่มีเมนูหรือปุ่ม UI รก
```
