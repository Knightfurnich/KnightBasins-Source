# ใบงานส่ง Replit — ระบบแสดงภาพตัวอย่างลายหินสังเคราะห์ขนาดสเกลจริง (Real-Scale Pattern Preview)

> ตามคำสั่งเจ้าของ (13 ก.ย. 2026): ทำข้อ 1 Real-Scale Pattern Preview แสดงสเกลลายหินสังเคราะห์จริงบนแผ่นและท็อปเคาน์เตอร์ยาว

---

## GOAL
ให้ลูกค้าและทีมขายสามารถกดดู **ภาพตัวอย่างลายหินสังเคราะห์แบบสเกลจริง (Real-Scale Pattern Preview)** ได้ทั้งบนแผ่นเต็ม (Full Slab 0.76 x 3.60 ม.) และบนท็อปเคาน์เตอร์ยาว เพื่อให้เห็นจังหวะสายแร่และลวดลายเสมือนจริงก่อนสั่งตัด โดยเฉพาะสีกลุ่มลายหินอ่อน (Veined Series)

---

## สิ่งที่ต้องทำ

### 1. เพิ่มโหมด Real-Scale Slab Preview ใน Lightbox & Catalogue
- ใน Modal/Lightbox ของการ์ดสี (ทั้งใน `/catalogue`, แผงน้องไนท์ และหน้าออกแบบ `/design`) เพิ่มโหมด **"ดูลายสเกลจริง (Real-Scale Slab View)"**
- แสดงภาพแผ่นหินเต็มแผ่น (Full Slab Image: `slabImageUrl`) พร้อมระบบไม้บรรทัดบอกสเกลขนาดจริง (เช่น 0.76 ม. x 3.60 ม.) 
- มีฟังก์ชัน **Interactive Zoom & Pan** ให้ลูกค้าสามารถใช้นิ้วเลื่อน/ซูมดูรายละเอียดเส้นสายแร่ในแต่ละจุดของแผ่นหินได้อย่างชัดเจน

### 2. แสดงสเกลลายหินจริงบนท็อปเคาน์เตอร์ในหน้าออกแบบ (`/design`)
- บนผืน Canvas 2D ในหน้าออกแบบ เมื่อผู้ใช้เลือกสีกลุ่มที่มีลายสายแร่ (เช่น Veined Tier: `KZ802`, `MS112`) ให้พื้นผิวของชิ้นงานบน Canvas ดึงลายแผ่นจริงมาวางแบบสเกลจริง (Seamless Texture / Scale-mapped Pattern)
- เมื่อเคาน์เตอร์ยาวขึ้น ลวดลายสายแร่ต้องยืดขยายตามสเกลความยาวจริงของชิ้นงาน ไม่ใช่การนำภาพชิปเล็กๆ มาต่อวนซ้ำ (Tiling) มั่วๆ

---

## เกณฑ์ตรวจรับ (แนบหลักฐานจริง)
```
1. กดดูรูปสีกลุ่ม Veined (เช่น KZ802, MS112) ใน Lightbox -> มีโหมด Real-Scale แสดงสเกลขนาด 0.76 x 3.60 ม. พร้อมซูมดูสายแร่ได้ชัดเจน (แนบภาพ)
2. บน Canvas หน้าออกแบบ (/design) -> เมื่อเลือกสีลายสายแร่ ลวดลายบนชิ้นงานแสดงตามสเกลความยาวจริง (แนบภาพ)
3. ทดสอบทั้ง Desktop และ Mobile เลื่อนซูมลายหินลื่นไหล ไม่ค้าง (แนบภาพ)
```
