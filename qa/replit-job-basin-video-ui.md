# ใบงานส่ง Replit — รองรับการแสดงผลวิดีโอ 3D อ่างล้างหน้า (Basin 3D Video) ใน Catalogue & Lightbox

> 13 ก.ย. 2026 · ต่อจากงานสร้างวิดีโอ 3D หมุน 360° อ่างทั้ง 30 รุ่นสำเร็จครบถ้วนโดยเดวิด (Hermes)

---

## GOAL
ให้การ์ดอ่างล้างหน้าและ Lightbox ซูมสินค้า แสดงวิดีโอ 3D หมุน 360° (`videoUrl`) ที่จัดเตรียมไว้ใน Catalogue เพิ่มเติมจากภาพถ่ายนิ่ง (`imageUrl`)

---

## สิ่งที่ต้องทำ

### 1. อัปเดต Type / Schema ของ Basin Model
- ใน Type หรือ Interface ของ Basin / Sink ใน Frontend (เช่น `artifacts/knightdesign-web/src/pages/design.tsx`, `support-selection.ts`, `support-catalogue-workbench.tsx`) เพิ่มฟิลด์ `videoUrl?: string`

### 2. การแสดงผลบน Lightbox ซูมสินค้า (Modal Viewer)
- เมื่อผู้ใช้กดที่ตัวรูปอ่างบนการ์ด เพื่อเปิด Lightbox ซูมดูสินค้าขนาดใหญ่:
  - หากสินค้านั้นมี `videoUrl` ให้แสดงวิดีโอ 3D หมุน 360° เล่นลูปอัตโนมัติ (Autoplay, Muted, Loop, Playsinline) ใน Lightbox
  - มีปุ่มสลับระหว่าง **"วิดีโอ 3D หมุน 360°"** และ **"ภาพถ่ายสินค้า (Photo)"** ให้ผู้ใช้เลือกดูได้ตามต้องการ

### 3. การแสดงผลบนการ์ดสินค้า (Thumbnail Hover / Preview Option)
- บนการ์ดอ่างใน Catalogue (`/catalogue` และแผงน้องไนท์):
  - เมื่อนำเมาส์ไปชี้ (Hover) ที่การ์ดอ่าง หรือมีสวิตช์เปิดดูพรีวิว ให้แสดงคลิปวิดีโอหมุน 360° เล่นสั้นๆ เป็นตัวอย่างมิติของอ่าง

---

## เกณฑ์ตรวจรับ (แนบหลักฐานจริง)
```
1. กดดู Lightbox ขยายรูปอ่างล้างหน้า -> มีวิดีโอ 3D หมุน 360° เล่นลูปชัดเจน + มีปุ่มสลับดูภาพถ่ายนิ่ง (แนบภาพ/คลิป)
2. บนการ์ดอ่างล้างหน้า -> รองรับฟิลด์ videoUrl จาก /api/pricing/catalogue (แนบภาพ)
```
