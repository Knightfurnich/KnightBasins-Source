# ข้อความส่ง Replit — ฉบับย่อสำหรับวางในแชท

> ฉบับเต็ม/ละเอียด: `knight-design-kb/qa/replit-prompt-basin.md` (ส่งไปได้เลยถ้า Replit ถามรายละเอียด)
> สร้าง 12 ก.ย. 2026 · สถานะที่ตรวจล่าสุด: prod ยังไม่มีความสามารถนี้ (bundle ยังไม่มี bowlMm)

---

งานรอบถัดไปของ KnightDesign — **"อ่างล้างหน้า: ขนาดจริง + หลายอ่าง"** (เป็นความสามารถใหม่ ไม่ใช่การแก้บั๊ก)

**สถานะตอนนี้**
- deploy ล่าสุดตรวจจริงผ่าน 18/18 (หน้าเว็บ · asset · 71 สีงานผลิต · ราคา 14,180)
- API ส่งข้อมูลอ่างมาแล้ว 2 ฟิลด์: `size_mm` = ขนาดตัวอ่าง และ `bowl_mm` = ขนาดหลุมที่ต้องเจาะ (pricing.ts:61-62)
- แต่ `bowl_mm` ยังไม่ถูกใช้เลยในโค้ดฝั่งเว็บ — งานนี้คือทำให้ใช้

⚠️ **กับดัก: `bowl_mm` เป็นข้อความ ไม่ใช่ตัวเลข**
`"350x500x130"` → แยกด้วย "x" แล้วหาร 1000 = 0.35 · 0.50 ม. (ไม่ต้องใช้ 130 = ความลึก)
รุ่นกลมขึ้นต้นด้วย Ø → `"Ø350x150"` = วงกลม Ø0.35 ม.
`KF029` / `KF030` = null (แคตตาล็อกไม่ระบุ) → **ห้ามเดาขนาดเอง** ให้แสดงข้อความ "ขนาดหลุมอ่างไม่ระบุในแคตตาล็อก"

**งานที่ 1 — วาดช่องเจาะตามขนาดจริง + ลากย้ายได้ + บันทึกใน draft**
ปัจจุบัน `design.tsx:538` ฝังตำแหน่ง 57% / 50% ตายตัว ไม่เกี่ยวกับขนาดอ่างจริง
เกณฑ์ตรวจรับ
1. เลือก KF003 → ช่องเจาะบนผังกว้าง 0.35 ม. × ยาว 0.50 ม. (วัดจาก DOM ได้)
2. เลือก KF023 (กลม) → วงกลม Ø 0.35 ม.
3. เลือก KF029 → ไม่วาดขนาด + แสดงข้อความไม่ระบุ
4. ลากช่องเจาะ → ตำแหน่งเปลี่ยน · บันทึก draft → โหลดกลับ → ตำแหน่งเดิม
5. ราคา/พื้นที่ต้องไม่เปลี่ยนจากตอนที่ยังไม่เลือกอ่าง

**งานที่ 2 — เลือกอ่างได้มากกว่า 1 ตัว**
แคตตาล็อกของบริษัทเอง (หน้า KF003) โชว์เคาน์เตอร์อ่างคู่ → งานจริงมี 2 อ่าง แต่โค้ดตอนนี้ `sinkModelCode?: string` เก็บได้อ่างเดียว
ต้องทำ: เปลี่ยนเป็นรายการ · เพิ่ม/ลบได้ · แสดงครบทุกตัวพร้อมขนาด · draft เก็บและโหลดกลับครบ
⛔ ห้ามคิดค่าอ่างเพิ่ม — `cutout_policy` ระบุค่าช่องเจาะรวมในเรต ตร.ม. แล้ว ถ้าจะคิดเพิ่มต้องรอเจ้าของยืนยันก่อน

**⛔ ห้ามทำพัง (ตรวจจริงแล้วว่าดี)**
- ราคา 0.60×1.80 SG420 กทม. = 9,180 + 5,000 = 14,180 · VAT 992.6 · รวม 15,172.6
- ราคา/พื้นที่ต้อง **ไม่เปลี่ยน** เมื่อเลือกอ่าง หรือเพิ่มอ่างตัวที่ 2
- `/assets/*` ที่ไม่มีไฟล์ → 404 (ห้ามถูก SPA fallback กลืน) · asset จริง → 200
- 71 สีงานผลิต + 71 รูป · 74 สีแผ่น · 30 อ่าง + viewer
- ไม่มี base64/data: URI ในคำตอบผู้ช่วย · เพดาน 4,000 ตัวอักษรยังอยู่

**กติกาการรายงาน** — ตาราง: ข้อ | สถานะ | ไฟล์ที่แก้ | หลักฐานจริง (คำสั่ง + ผล)
ห้ามรายงานว่า "ผ่าน" ลอย ๆ ต้องมีตัวเลข/ข้อความจริง · ข้อไหนไม่ได้ทำบอกตรง ๆ พร้อมเหตุผล
ถ้าเจอว่าคำสั่งขัดกับ "ห้ามทำพัง" ให้ถามก่อน อย่าเลือกเอง
