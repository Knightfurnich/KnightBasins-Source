# ใบงาน Replit (ฉบับรวมสุดท้าย) — ส่งออกผัง Studio เป็น DXF/PDF (Task #71 ระดับ 1)
สร้าง 15 ก.ย. 2026 · แอป Knight Basins · repo Knightfurnich/KnightBasins-Source
(งานข้ามคืนชุดก่อนหน้าปิดครบแล้ว: ผัง L/U ทรงจริง · ปัดเศษยอด · ปุ่มกด Telegram · หน้า้นหาใบเสนอราคา — ไม่ต้องทำซ้ำ)

## วัตถุประสงค์ที่ผู้ใช้อนุมัติ
1. ให้ช่างแบบเปิดวัดขนาด (ทีมงานใช้ SketchUp)
2. ให้ลูกค้าดูแบบ → ต้องได้ PDF ด้วย เพราะลูกค้าเปิด DXF ไม่ได้
**ไม่ใช่ระดับ CNC** → รอบนี้ไม่ต้องใส่ความหนาแผ่น · แนวเชื่อมต่อ · รัศมีมุม

## ขอบเขตงาน
1. ปุ่ม **"ดาวน์โหลดแบบ (DXF)"** และ **"ดาวน์โหลดแบบ (PDF)"** — มีทั้งหน้า Studio และหน้า saved quote
2. **DXF หน่วยมิลลิเมตรแท้** (1 unit = 1 mm) พิกัดตามขนาดจริงที่กรอก — ต้องเปิดใน SketchUp Pro ได้ตรง ๆ
3. รองรับผัง **I / L / U** ตามสัดส่วน A / B / C × ความลึก
4. **ใช้ geometry ชุดเดียวกับที่หน้าเว็บใช้คำนวณและตรวจความปลอดภัย** (ห้ามเขียนสูตรซ้ำ — กันเลขไม่ตรงกัน)
5. **แยกเลเยอร์** ในไฟล์ DXF:
   - `COUNTER_OUTLINE` ขอบเคาน์เตอร์ตามรูปทรงจริง
   - `CLEARANCE_50` เส้นระยะขอบ 50 มม. ตามรูปทรงจริง
   - `BASIN_HOLES` กรอบหลุมอ่างตามขนาดจริง
   - `BASIN_LABELS` ป้ายรหัสรุ่น (SKU)
   - `DIMENSIONS` เส้นบอกขนาด A / B / C และความลึก
   - `NOTE` ข้อความกำกับ
6. ในเลเยอร์ `NOTE` ต้องมีข้อความ:
   `แบบอ้างอิงเพื่อการนำเสนอ ไม่ใช่แบบผลิตหรือแบบ CNC — ต้องตรวจสอบหน้างานก่อนผลิต`
7. รุ่นที่แคตตาล็อกไม่ระบุขนาดหลุม → วาดเป็น **กรอบเส้นประ** + ข้อความ `แคตตาล็อกไม่ระบุขนาดหลุม` (ห้ามเดาขนาด)
8. ชื่อไฟล์สื่อความหมาย เช่น `<เลขที่ใบเสนอราคา>-<ทรง>.dxf` และ `.pdf`
9. PDF ต้องหน้าตาเดียวกับผังที่แสดงในใบเสนอราคา
10. **automated tests**: รูปทรง I/L/U · ขนาด · ตำแหน่งอ่าง · กรณีไม่มีขนาดหลุม · หน่วยเป็นมิลลิเมตร

## เกณฑ์ตรวจรับ (แนบหลักฐานจริงทีละข้อ)
1. ดาวน์โหลด DXF ได้จากหน้า Studio และหน้า saved quote (แนบภาพ)
2. เปิดไฟล์ DXF แล้วเห็นรูปทรงถูกต้องตามที่เลือก — I / L / U อย่างละ 1 ไฟล์ (แนบภาพ)
3. พิกัดในไฟล์เป็นมิลลิเมตรจริงตรงกับขนาดที่กรอก (แนบภาพ)
4. เลเยอร์ครบทั้ง 6 ชื่อตามที่กำหนด และมีข้อความใน NOTE (แนบภาพ)
5. รุ่นที่ไม่ระบุขนาดหลุมขึ้นกรอบเส้นประ + ข้อความถูกต้อง (แนบภาพ)
6. PDF ที่ดาวน์โหลดได้ เหมือนผังในใบเสนอราคา (แนบภาพ)
7. ผลรันเทสต์ทั้งหมดผ่าน + build/asset guard ผ่าน (แนบผลรัน)
