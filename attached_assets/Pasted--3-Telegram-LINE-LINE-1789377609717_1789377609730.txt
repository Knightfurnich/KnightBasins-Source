งานชุดที่ 3 เรื่อง — ทำช่องทางแจ้งเตือนเป็น Telegram ก่อน (LINE กลุ่มยังไม่พร้อม) แต่ต้องสลับไป LINE ทีหลังได้ด้วยการตั้งค่า ไม่ต้องรื้อโค้ด

ตัวแปร env (อ่านจาก env เท่านั้น ห้าม hardcode ลงโค้ดหรือ bundle — เดวิดตั้งให้บน VPS เอง):
NOTIFY_CHANNEL=telegram
TELEGRAM_BOT_TOKEN / TELEGRAM_SALES_CHAT_ID
LINE_CHANNEL_ACCESS_TOKEN (ของเดิม ยังไม่ใช้รอบนี้ แต่โค้ดต้องยังอยู่)
ถ้า env ไม่ครบ ห้ามทำให้การส่งใบเสนอราคา/แบบร่างล้มเหลว — ต้องบันทึกสำเร็จเสมอ แล้วแจ้งหน้าจอว่า "บันทึกแล้ว แต่ยังไม่ได้ส่งแจ้งเตือน"

งาน A: ใบเสนอราคาโหมด "ซื้อด่วน" ต้องบันทึกและแชร์ลิงก์ได้
1. กด "ออกใบเสนอราคาทางการ" → บันทึกลงฐานข้อมูลจริง (ใช้ตาราง customer_leads + คอลัมน์ quote_number / studio_data เดิม ไม่สร้างตารางใหม่)
2. ออกเลขที่ใบเสนอราคารูปแบบเดียวกับโหมด 2D · ส่งซ้ำด้วย leadKey เดิมได้เลขเดิม
3. พาไปหน้า /quote/view?quote=... (ใช้ component เดิมของโหมด 2D)
4. มีปุ่ม "คัดลอกลิงก์ใบเสนอราคา"
5. เปิด read-only ได้โดยไม่ต้องล็อกอิน
6. หน้าใบเสนอราคาที่เปิดซ้ำต้องเห็นรายการหิน/อ่าง/ค่าติดตั้ง/ค่าำเนินการ และยอดรวมเท่าเดิม

งาน B: ปุ่ม "ส่งเข้า Telegram" (เดิมตั้งใจเป็น LINE)
- ใส่บนหน้าใบเสนอราคาที่บันทึกไว้ และหน้า /quote
- ส่งข้อความสรุปเข้าแชตทีมขาย: เลขที่ใบเสนอราคา · ชื่อลูกค้า/โครงการ · รายการ · ยอดรวม · ลิงก์ read-only (ผ่าน Telegram Bot API sendMessage)
- แสดงผลบนหน้าจอทันที: ส่งสำเร็จ / ส่งไม่สำเร็จ พร้อมเหตุผล ห้ามเงียบ · กดซ้ำได้

งาน C: โหมด "ส่งแบบร่างด้วยมือ" แจ้งเตือนทาง Telegram
- บันทึกสำเร็จเสมอ แล้วส่งเข้า Telegram เป็นรูปภาพ + คำบรรยาย (sendPhoto) ใช้ URL รูปที่ระบบออกให้อยู่แล้ว · คำบรรยายมี ชื่อ/โทร/โครงการ/รุ่นอ่างที่สนใจ/ลิงก์ใบเสนอราคา (ถ้ามี)
- หน้าจอแสดง "ส่งแบบร่างให้ทีมขายแล้ว" หรือ "บันทึกแล้ว แต่ยังไม่ได้แจ้งเตือน"

เกณฑ์ตรวจรับ (แนบหลักฐานจริงทีละข้อ):
1. ซื้อด่วน → กดออกใบเสนอราคา → ได้เลขที่ + หน้าลิงก์ที่เปิดซ้ำได้ (แนบภาพ)
2. เปิดลิงก์ซ้ำ → รายการและยอดเท่าเดิม (แนบภาพก่อน-หลัง)
3. ปุ่มคัดลอกลิงก์ทำงาน และเปิดลิงก์ได้โดยไม่ล็อกอิน (แนบภาพ)
4. กด "ส่งเข้า Telegram" → ข้อความมาถึงจริง พร้อมข้อความยืนยันบนหน้าจอ (แนบภาพหน้าจอ + ภาพข้อความที่ได้รับ)
5. ส่งแบบร่างด้วยมือ → รูป + ข้อความมาึง Telegram (แนบภาพ)
6. ไม่มี token → ใบเสนอราคายังบันทึกสำเร็จ และขึ้นข้อความว่าไม่ได้แจ้งเตือน (แนบภาพ)
7. โหมด 2D เดิมยังทำงาน: snap 50 มม. · ลิงก์ที่บันทึกไว้เปิดได้ · ห้ามหักพื้นที่ช่องเจาะอ่าง (แนบภาพ)

ห้ามแตะ: Auth/Session · Admin Guard · Persona น้องไนท์ · ข้อมูลอ่างและราคาในฐานข้อมูล · รุ่นกลมต้องเป็น Ø ห้าม D · กฎราคาเดิม · ห้ามใส่ token ลงโค้ดหรือ bundle
