งาน 2: ยอดเงินปัดเป็นจำนวนเต็มบาท (ข้อความ Telegram, คำบรรยายแบบร่าง, ใบเสนอราคาที่พิมพ์)

งาน 3: ข้อความแบบร่าง (hand sketch) เลิกแสดงลิงก์ซ้ำ
- ถ้ามีเลขที่ใบเสนอราา → แสดงลิงก์ใบเสนอราาตามปกติ
- ถ้าไม่มี → ตัดบรรทัด "ลิงก์:" ออก แล้วต่อท้ายด้วย "(แนบรูปมาแล้วในข้อความนี้)"

งาน 4: เพิ่มปุ่มกดในข้อความ Telegram (Inline Keyboard)
- ข้อความใบเสนอราคา → ปุ่ม "เปิดใบเสนอราคา" (ลิงก์ read-only เดียวกับบรรทัดลิงก์)
- ข้อความแบบร่าง → ปุ่ม "เปิดดูรูปเต็ม"
- ต้องยังส่งข้อความได้ปกติถ้าตั้งค่า Telegram ไม่ครบ (ห้าม error) · ห้ามใส่ token ลงโค้ดหรือ bundle

งาน 5: หน้ารวมใบเสนอราคาสำหรับทีมขาย — เพิ่มในหน้า /admin/leads ที่มีอยู่ (ไม่สร้างระบบใหม่)
- ช่องค้นหา: เลขที่ใบเสนอราคา / ชื่อลูกค้า / ชื่อโครงการ / เบอร์โทร
- แสดงเลขที่ใบเสนอราคา + ปุ่ม "คัดลอกลิงก์" ในแต่ละรายการ
- กรองช่วงวันที่ (วันนี้ / 7 วัน / 30 วัน)
- ต้องยังอยู่หลัง Admin Guard (ผู้ไม่ล็อกอินเข้าไม่ได้) · ห้ามแก้ข้อมูลลูกค้าเดิม

งาน 6: เพิ่มเทสต์สำหรับงาน 1–4 และรันชุดเดิมทั้งหมดต้องผ่าน + production asset guard และ build guard ของเดิมต้องผ่าน

เกณฑ์ตรวจรับ (แนบหลักฐานจริงทีละข้อ):
1. ป้ายผัง L/U แสดงด้าน B/C ครบ (แนบภาพผัง + ภาพ saved quote)
2. ยอดในข้อความ Telegram เป็นจำนวนเต็มบาท ไม่มีทศนิยม (แนบภาพ)
3. ข้อความแบบร่างไม่มีลิงก์ซ้ำ มีข้อความ "(แนบรูปมาแล้วในข้อความนี้)" (แนบภาพ)
4. ข้อความ Telegram มีปุ่มกดทั้งสองแบบ (แนบภาพ)
5. /admin/leads ค้นหาเลขที่เจอ กรองวันที่ได้ และผู้ไม่ล็อกอินเข้าไม่ได้ (แนบภาพ)
6. ผลรันเทสต์ + build guard ผ่าน (แนบผลรัน)
