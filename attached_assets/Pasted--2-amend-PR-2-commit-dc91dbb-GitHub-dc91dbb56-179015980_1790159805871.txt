จุดที่ 1 — createBasinPlacement() สร้าง placement ที่ไม่มี sheetId ได้
ยอมรับว่าจริง และแก้แล้ว 2 ชั้น:

- pieceId บังคับแล้ว — ตัด ? ออก (pieceId: string) เรียกโดยไม่ระบุชิ้นงานไม่ได้อีก (call site เดิมทั้ง 3 จุดใน StudioPage ส่ง piece.id อยู่แล้ว จึงไม่กระทบ)
- เพิ่ม placementTargetWarnings(placement, pieces) เป็นตัวบังคับสัญญาใหม่: เตือนเมื่อ (ก) ไม่มี pieceId (ข) ชี้ pieceId ที่ไม่มีจริง — ไม่ fallback ไปชิ้นงานแรก (ค) ไม่มี sheetId (ง) ชี้ sheetId ที่ไม่อยู่ในชิ้นงานนั้น
- placementSheetWarnings แยกข้อความ "ไม่ได้ระบุแผ่น" ออกจาก "ไม่พบแผ่นเป้าหมาย" แล้ว

ข้อจำกัดที่ต้องรายงานตรงๆ 1 เรื่อง: การบังคับให้ sheetId เป็น required ที่ระดับ type ทำใน WO-1 ไม่ได้ครับ เพราะจะทำให้ 3 call site ใน StudioPage.tsx (บรรทัด 479, 700, 920) เป็น type error ทันที — ซึ่งคือการแตะ .tsx ที่คุณนพห้ามไว้สำหรับใบงานนี้

มี 2 ทาง เลือกได้ครับ:
- (ก) คงไว้แบบนี้แล้ว merge — WO-1 ยังสะอาดเป็น model+tests ล้วน แล้วให้ WO-3 ทำ 2 อย่างบังคับ: ส่ง sheetId ของแผ่นที่ผู้ใช้เลือกที่ 3 จุดนั้น + เรียก placementTargetWarnings ในขั้น validation
- (ข) อนุญาต exception ตอนนี้ — ให้ WO-1 แก้ 3 บรรทัดใน StudioPage.tsx (แก้แค่การส่ง argument ไม่แตะ logic/หน้าจอ) แล้ว sheetId เป็น required ตั้งแต่วันนี้

เดวิดแนะนำ (ก) ครับ เพราะตรงกับหลัก "UI ค่อยแก้ใน WO-3" และตัวตรวจสัญญาก็มีอยู่จริงแล้ว
