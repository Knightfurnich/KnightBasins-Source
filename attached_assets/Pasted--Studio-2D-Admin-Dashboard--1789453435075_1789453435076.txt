📋 ใบงานย่อยส่ง Replit: คำแนะนำฟิลด์กรอกข้อมูล หน้าบ้าน Studio 2D + ระบบป้องกัน Admin หลังบ้าน

ใบงานย่อย — ปรับปรุงคำแนะนำฟิลด์กรอกข้อมูลหน้าบ้าน Studio 2D และระบบป้องการกรอกผิดฝั่ง Admin

1. ปรับปรุงคำแนะนำฟิลด์หน้าบ้าน (Studio 2D Helper Text & Auto-Clean):
   - เพิ่ม Helper Text / Tooltip ใต้ช่องขนาด: "หน่วย มิลลิเมตร (มม.) เช่น 600 มม. = 60 ซม. / 1800 มม. = 1.8 เมตร"
   - ปุ่มสลับ กว้าง ↔ ยาว อัตโนมัติ: หากกรอกความกว้าง (แนวลึก) เกิน 900 มม. ให้ขึ้นกล่องแนะนำย่อพร้อมปุ่ม "🔄 สลับ กว้าง ↔ ยาว"
   - คำอธิบายสถานะรายด้าน: แสดงคำอธิบายย่อใต้สถานะรายด้าน "ติดบัว = ชิดผนังปูน / ขอบเปิด = โชว์ลอยในอากาศ"
   - ทำความสะอาดช่องเบอร์โทรอัตโนมัติ (Phone Auto-Clean): ตั้ง Placeholder "0812345678 (10 หลัก)" และเมื่อผู้ใช้พิมพ์ขีด - หรือเว้นวรรค ให้ลบออกอัตโนมัติเหลือเฉพาะตัวเลข 10 หลัก

2. ระบบป้องกันการกรอกผิดฝั่งหลังบ้าน (Admin Dashboard Guards):
   - ตรวจจับสัญลักษณ์อ่างทรงกลม (Basin Round Symbol Guard): ในฟอร์มเพิ่ม/แก้ไขอ่าง หากป้อน D350x150 (ใช้ตัว D) ให้แปลงเป็น Ø350x150 (สัญลักษณ์ Ø) หรือขึ้นคำเตือนทันที
   - อ่างทรงสูง KF029 / KF030: บล็อกช่องขนาดหลุมเจาะ bowl_mm ห้ามป้อนตัวเลข ให้เป็น null ตามแคตตาล็อกจริง
   - ทำความสะอาดฟิลด์ตัวเลขราคา (Price Field Sanitizer): ลบเครื่องหมายคอมม่า , หรือสัญลักษณ์ ฿ ออกจากช่องราคาอัตโนมัติก่อนบันทึก

เกณฑ์ตรวจรับ (แนบหลักฐานจริง):
- หน้า Studio 2D แสดง Helper Text หน่วยมิลลิเมตร และข้อความแนะนำสถานะรายด้านชัดเจน (แนบภาพ)
- พิมพ์เบอร์โทรมีขีด 081-234-5678 แล้วระบบลบขีดออกเหลือตัวเลข 10 หลักติดกันอัตโนมัติ (แนบภาพ)
- กรอกขนาดลึกเกิน 900 มม. แล้วมีปุ่มสลับ กว้าง ↔ ยาว แสดงขึ้นมาถูกต้อง (แนบภาพ)
- หน้า Admin ลองป้อน D350x150 แล้วระบบเตือน/แปลงเป็น Ø350x150 ทันที (แนบภาพ)
- Storefront & Admin tests ผ่าน 100%
- ห้ามแตะ Auth/Session/Admin Guard และห้าม deploy production เอง
