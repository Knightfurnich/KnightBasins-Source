โมเดลใหม่: ประกอบผังจากสี่เหลี่ยม
ช่างตัดเคาน์เตอร์เป็นแผ่นสี่เหลี่ยมแล้วนำมาประกอบเป็น L/U/I ตัวอย่างจริง: ตัว L = 2 แผ่น → 1420×620 + 3170×620 = 2.8458 ตร.ม. ไม่มีการเลือก "ทรง" แล้ว รูปทรงเกิดจากจำนวน/การจัดวางสี่เหลี่ยมเอง

ข้อกำหนดโมเดล:
1. 1 ใบเสนอราคา = สูงสุด 3 ชิ้นงาน
2. 1 ชิ้นงาน = ประกอบจากสี่เหลี่ยม สูงสุด 6 อัน
3. แต่ละสี่เหลี่ยม: กรอก กว้าง × ยาว (มม.) และสลับแนวนอน/แนวตั้งได้
4. จัดเรียงบนผังได้ ขอบที่ชนกันให้ snap ต่อกัน ถ้าซ้อนทับกันให้เตือน (ห้ามคิดพื้นที่ซ้ำ)
5. พื้นที่งาน = ผลรวมพื้นที่สี่เหลี่ยมทุกอัน (ไม่หักมุมเอง เพราะผู้ใช้กำหนดขนาดแผ่นเอง)
   เคสทดสอบ: 1420×620 + 3170×620 = 2.8458 · 2040×760 = 1.5504 · รวม 4.3962 ตร.ม.
6. ชิ้นงานที่มีขั้น/รอยบาก = อีกสี่เหลี่ยมหนึ่งอัน ต้องวาดได้ตามจริง (ไม่ใช่แสดงแค่สี่เหลี่ยมฐาน)
7. ยกเลิกกฎระยะขอบ 50 มม. ทั้งหมด — ไม่วาด ไม่เตือน ไม่บล็อกการส่ง (แบบนี้ให้ช่าง/ลูกค้าดู ไม่ได้ทำ nesting ต่อ)
8. เส้นประ = แนวรอยต่อระหว่างแผ่น และระบุ "ต่อแผ่นแล้วต้องได้ฉาก 90°"
9. โหมดด่วน (ลูกค้าั่วไป) ยังติ๊ก "มีบัวด้านหลัง" แบบเดิมได้

ความหมายสัญลักษณ์:
- ▲ = ติดตั้งบัวตลอดแนวนั้น (มีผลต่อราคา — คิด ตร.ม. ตามเรตสี)
- ⊗ วงกลมกากบาท = ขอบเปิดโชว์ตามแนวนั้น ขนาด 24/30 มม. (มีผลต่อราคา — คิดเป็นเมตร)
- ขีดคู่ = ด้านเท่ากัน + ชิดผนัง ไม่ใช่ขอบเปิด (ไม่มีผลต่อราคา)
- เส้นประ = แนวรอยต่อระหว่างแผ่น ต้องได้ฉาก 90° (ไม่มีผลต่อราคา)
- เส้นบอกขนาด = ครบทุกด้าน หน่วย มม.
- ตั้งสถานะรายด้านได้: ติดบัว / ขอบเปิด / ชิดผนัง / ปกติ (ด้านเดียวมีสถานะเดียวเท่านั้น)
- ด้านที่ใช้ร่วมกันระหว่างแผ่นที่ชนกัน นับครั้งเดียว และตั้งสถานะครั้งเดียว
- สถานะรายด้านผูกกับแต่ละชิ้นงาน และติดไปกับใบเสนอราคา + ข้อความ Telegram

ราคา (ผู้ใช้ยืนยันแล้วทุกข้อ):
1. หิน = พื้นที่งาน × เรตสีที่เลือก (ตามเดิม)
   · สีเรต 9,500 (ลายหินอ่อน สายแร่) เล่มระบุฐาน = "แผ่นตัด" → ห้ามคิดอัตโนมัติ ให้ขึ้นคำเตือน "สีลายหินอ่อนคิดตามแผ่นตัด ทีมขายจะคิดให้" และไม่รวมยอดอัตโนมัติ
2. บัว = (ความยาวแนวบัว × ความสูงบัว) × เรตสีที่เลือก
   · ความสูงบัว default 120 มม. แก้ไขได้ ห้ามเป็นค่าว่าง (ว่าง → ไม่คิดเงินบัว + แสดงคำเตือน)
3. ขอบเปิด = ความยาว × ราคาต่อเมตร (ทีมขายกรอกเอง)
   · ว่าง = ยังไม่กรอก → เตือน · 0 = ตั้งใจฟรี → แสดง "ฟรี" ไม่เตือน · ติดลบ = ห้าม · ทศนิยม 2 ตำแหน่ง
4. ค่าดำเนินการงานพื้นที่เล็ก ตาม KB: กทม./ปริมณฑล พื้นที่งาน < 5 ตร.ม. = 5,000 · ต่างจังหวัด < 10 ตร.ม. = 8,000
   · พื้นที่งาน = พื้นที่เคาน์เตอร์ + พื้นที่บัว
5. ส่วนลด — ต้องมีช่องส่วนลด (ก่อน VAT) และยังมีสิทธิ์ติดตั้งฟรีเมื่ออ่างครบ 3 ชุด
6. VAT 7% = คิดจากยอดหลังหักส่วนลดทั้งหมด + ค่าดำเนินการงานพื้นที่เล็ก
7. การปัดเศษ: คูณด้วยค่าละเอียด (ห้ามใช้ค่าที่ปัดแล้วคูณ) → ปัดเป็นจำนวนเต็มบาททีละบรรทัด แล้วจึงรวมยอด
8. อ่างตามเดิม: คิดเป็นใบ · ค่าติดตั้ง 5,000/ชุด · ฟรีเมื่อ 3 ชุด · ห้ามหักพื้นที่ช่องเจาะอ่าง
