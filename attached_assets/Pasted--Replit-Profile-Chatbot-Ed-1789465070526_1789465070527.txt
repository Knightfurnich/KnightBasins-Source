📋 ใบงานย่อยส่ง Replit: ปรับปรุงความเสถียรโปรไฟล์ ภาษี และคำยืนยันน้องไนท์

ใบงานย่อย — ปิดช่องโหว่ความเสถียรโปรไฟล์ ภาษี และคำยืนยันน้องไนท์ (Profile & Chatbot Edge Cases)

1. ปรับปรุงคำยืนยัน/ยกเลิกของน้องไนท์ (Chatbot Polite Suffix Matching):
   - ปรับ Regex ใน support-profile.ts ให้รองรับคำสุภาพต่อท้าย เช่น:
     * คำยืนยัน: "ยืนยันครับ", "ยืนยันค่ะ", "ตกลงครับ", "ตกลงค่ะ", "โอเคครับ", "confirm krub", "ยืนยันนะคะ"
     * คำยกเลิก: "ยกเลิกครับ", "ยกเลิกค่ะ", "ไม่ต้องการครับ", "cancel ka"
   - ห้ามเด้งไปตอบคำถามสินค้าทั่วไปหากข้อความมีคำยืนยันหลัก

2. รวมข้อมูลโปรไฟล์ย่อยในแชต (Multi-message Field Merging):
   - หากลูกค้าส่งข้อมูลโปรไฟล์ชุดที่สองเข้ามา ขณะที่มีข้อมูลเดิมรอการยืนยันอยู่ (Pending Confirmation):
     * ให้นำข้อมูลใหม่มา Merge รวมกับข้อมูลเดิมที่รออยู่ ไม่เขียนทับข้อมูลย่อยเดิมหลุดหาย

3. ตรวจสอบเลขประจำตัวผู้เสียภาษี 13 หลัก (Tax ID Format Validation):
   - ในหน้าโปรไฟล์ลูกค้า (Customer Profile Page) หากกรอกเลขภาษี ให้ตรวจสอบว่าเป็นตัวเลข 13 หลัก (0-9) เท่านั้น
   - หากกรอกไม่ครบ 13 หลัก ให้แสดงข้อความเตือนใต้ช่องกรอก: "กรุณากรอกเลขประจำตัวผู้เสียภาษีให้ครบ 13 หลัก"

4. จำกัดวันที่เข้าติดตั้ง (Min Date Validation):
   - ในฟอร์มเลือกวันเข้าติดตั้ง (Expected Installation Date) บล็อกไม่ให้เลือกวันที่ในอดีต (min = วันปัจจุบัน YYYY-MM-DD)

5. คำเตือนเลขภาษีเมื่อกดคิด VAT 7%:
   - เมื่อกดเลือก "คิด VAT 7%" ในหน้า Studio 2D หรือ Quote แต่ในโปรไฟล์ยังไม่ได้กรอก Tax ID ให้แสดงข้อความแนะนำสีส้มอ่อน: "💡 กรุณากรอกเลขประจำตัวผู้เสียภาษี 13 หลักในโปรไฟล์เพื่อให้ออกใบกำกับภาษีได้สมบูรณ์"

เกณฑ์ตรวจรับ (แนบหลักฐานจริง):
- ทดสอบพิมพ์ "ยืนยันครับ" หรือ "ยืนยันค่ะ" น้องไนท์ประมวลผลอัปเดตข้อมูลสำเร็จ (แนบภาพ)
- ลองกรอกเลขภาษีไม่ครบ 13 หลักในโปรไฟล์ ระบบแสดงข้อความเตือนถูกต้อง (แนบภาพ)
- Storefront & API tests ผ่าน 100%
- ห้ามแตะ Auth/Session/Admin Guard เดิม และห้าม deploy production เอง
