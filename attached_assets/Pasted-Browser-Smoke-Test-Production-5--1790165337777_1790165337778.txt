✅ ผลทดสอบทีละข้อ (หลักฐานจาก DOM จริงบน production)

1. เปิด Studio — /studio โหลดปกติ (หัวข้อ "ประกอบแผ่นจริง ให้เห็นภาพก่อนขอราคา")

2. สร้างงานหลายชิ้น — กด "เพิ่มชิ้นงาน" แล้ว h2 เปลี่ยนเป็น "ผังประกอบ 2 ชิ้นงาน" และมี canvas แยก 2 ตัว

3. วางอ่างแยกชิ้นงาน (พิสูจน์ว่าไม่ผูกชิ้นแรก) — ลาก KF001 ลงชิ้นงาน 1 และ KF002 ลงชิ้นงาน 2 ได้ placement:
studio-print-placement-piece-...98986-0-KF001-0   ← ชิ้นงาน 1
studio-print-placement-piece-...89542-1-KF002-1   ← ชิ้นงาน 2


ตรวจ Inspector ของอ่างบนชิ้นงานที่ 2:
anchorOptions: [top-left, top-right, bottom-left, bottom-right, center]
anchorValue: "top-left"
sheetValue: "rectangle-...89542-1 | แผ่นต่อ · 1800 × 600 มม."   ← ชี้แผ่นของชิ้นงาน 2 ถูกต้อง
offsetX: 0 · offsetY: 50
rotateBtn: button-rotate-studio-basin-KF002-...
warnings: []

สลับ anchor → bottom-right แล้ว offset คงเดิม (0, 50) ตามสัญญา · กดปุ่มหมุนแล้ว footprint ของอ่างเปลี่ยนจริง (style width/height สลับ) และยังไม่มี warning

4. บันทึกและเปิด draft — บันทึกชื่อ "SMOKE-หลายชิ้นงาน 2 piece" → ปุ่มขึ้น "แบบร่างของฉัน (1)" → hard reload หน้าใหม่ แล้วเปิด draft กลับมา:
h2: ผังประกอบ 2 ชิ้นงาน
placements: [ ...piece-...98986-0-KF001..., ...piece-...89542-1-KF002... ]

การ์ด draft แสดง ชิ้นงาน 1 (5000×5000, KF001) + ชิ้นงาน 2 (1800×600, KF002) · 26.08 m² · อ่าง 2 จุด · ฿243,600

5. ส่ง quote — กรอกข้อมูลครบแล้วส่งสำเร็จ → เข้าหน้า Saved Quote ได้ลิงก์จริง:
/quote/view?token=...  ·  hasSavedQuotePage: true
เลขที่ใบเสนอราคา: Sep 26 / US / 208317


6. ตรวจ print layout (emulate @media print)
printMediaMatches: true
pieceCount: 2
ชิ้นงาน 1 → KF001 · display: block · 1920×1920  (แผ่น 5000×5000)
ชิ้นงาน 2 → KF002 · display: block · 1920×320   (แผ่น 1800×600)
หัวข้อ: "SAVED 2D STUDIO LAYOUT ... 2 ชิ้นงาน · 2 แผ่น"

✅ อ่างครบทั้ง 2 ชิ้น และไม่ถูกย้ายไปรวมที่ชิ้นแรก ตรงตามที่งาน #214 ต้องแก้

📌 2 เรื่องที่ต้องอธิบายให้ชัด (ก่อนเข้าใจผิดว่าเป็นบั๊ก)

1. เลขที่ใบเสนอราคา "Sep 26" ไม่ใช่ผิดวัน — เดวิดเช็กโค้ดแล้ว formatQuoteMonth() ใช้ month: short + year: 2-digit ในเขตเวลาไทย → "Sep 26" = เดือนกันยายน ปี 2026 ไม่ใช่ "26 กันยายน" (วันนี้ 23 ก.ย. 2569 / 19:0x น. ไทย)
