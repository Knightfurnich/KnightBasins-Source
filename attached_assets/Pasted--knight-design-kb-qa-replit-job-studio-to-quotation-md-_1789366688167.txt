ใบงานเขียนเสร็จแล้วครับ (เก็บไว้ที่ knight-design-kb/qa/replit-job-studio-to-quotation.md)

💬 คัดลอกข้อความด้านล่างนี้ส่งให้ Replit ได้เลยครับ:

งานที่ 1: ทำให้ผัง 2D ออกใบเสนอราคาจริงได้ + บันทึกแบบไว้ดูซ้ำได้ (แอป Knight Basins)

เป้าหมาย: จากผัง 2D Studio ที่ลูกค้าวางเอง → กดปุ่มแล้วได้ใบเสนอราคาจริงที่มีตัวเลขครบ และเปิดกลับมาดูซ้ำได้

สิ่งที่ต้องทำ:
1. ปุ่ม "ขอใบเสนอราคาจากแบบนี้" ต้องสร้าง "ใบเสนอราคา" จริง (ไม่ใช่แค่รายการลูกค้านใจ) แล้วพาผู้ใช้ไปหน้าใบเสนอราคาที่แสดงรายการครบตามผัง
2. บันทึกแบบลงฐานข้อมูลผูกกับเลขที่ใบเสนอราคา: รูปทรง (I/L/U), ขนาด, backsplash, สีที่ใช้คำนวณ, รายการอ่าง + ตำแหน่งที่วาง (x,y), พื้นที่ติดตั้ง
3. เปิดดูซ้ำได้: เปิดลิงก์เดิมแล้วเห็นแบบ + ตำแหน่งอ่างเหมือนเดิมทุกจุด (รีเฟรช หรือคนละเครื่องก็ได้)
4. ลิงก์ read-only: คนที่ไม่ได้ล็อกอินแอดมินเปิดดูได้ แต่แก้ไม่ได้
5. ใบเสนอราคาที่พิมพ์/บันทึก PDF ต้องแสดงแบบที่บันทึกไว้ถูกต้อง

กฎราคา (ห้ามคิดใหม่):
- หิน = (กว้าง × ยาว) + backsplash (ถ้าติ๊ก) × เรตรวมติดตั้งของสีที่เลือก
- ห้ามหักพื้นที่ช่องเจาะอ่างออกจากพื้นที่หิน · ห้ามบวกค่าขอบ/ค่าเจาะ
- อ่างคิดเป็นจำนวนใบ · ค่าติดตั้ง 5,000 บาท/ชุด · ฟรีเมื่อสั่งตั้งแต่ 3 ชุด
- ค่าดำเนินการงานพื้นที่เล็ก: กทม./ปริมณฑล ต่ำกว่า 5 ตร.ม. = 5,000 · ต่างจังหวัด ต่ำกว่า 10 ตร.ม. = 8,000
- เกิน 0.76 × 3.60 ม. ต้องเตือนเรื่องรอยต่อ
- ระยะขอบอ่าง ≥ 50 มม. และรุ่นที่ไม่ระบุขนาดหลุม ยังคงบล็อกการส่งเหมือนเดิม
- VAT 7% เป็นตัวเลือก ต้องไม่บังคับเปิดเอง

เกณฑ์ตรวจรับ (แนบหลักฐานจริงทีละข้อ):
1. กดจากผัง 2D → ได้ใบเสนอราคาที่มีทั้งรายการหินและอ่าง พร้อมเลขที่เอกสาร (แนบภาพ)
2. รีเฟรช/เปิดลิงก์เดิม → แบบและตำแหน่งอ่างเหมือนเดิมทุกจุด (แนบภาพก่อน-หลัง)
3. เปิดลิงก์ด้วยเบราว์เซอร์ที่ไม่ได้ล็อกอินแอดมิน → ดูได้ แก้ไม่ได้ (แนบภาพ)
4. ตรวจเลข: ผัง 1.80 × 0.60 ม. + backsplash สี 7,500/ตร.ม. → พื้นที่หิน 1.26 ตร.ม. = 9,450 · อ่าง 3 ใบ × 19,000 = 57,000 (ค่าติดตั้งฟรี) · ค่าดำเนินการ 5,000 → รวม 70,100 (แนบภาพ)
5. ใส่ 2 อ่าง → ยังคิดค่าติดตั้ง 5,000/ชุด (แนบภาพ)
6. ใส่/ถอดอ่างแล้วพื้นที่หินต้องเท่าเดิม (ไม่หักช่องเจาะ) (แนบภาพ)

ห้ามแตะ: ระบบล็อกอิน/เซสชัน · Admin Guard · Persona น้องไนท์ · ข้อมูลอ่างและราคาในฐานข้อมูล · รุ่นกลมต้องเป็น Ø ห้าม D

การส่งงาน: push ขึ้น GitHub Knightfurnich/KnightBasins-Source branch main ทั้ง source และโฟลเดอร์บิลด์ api-dist/ + web-dist/ แล้วแจ้ง SHA-256 ของ zip (ห้ามส่ง zip ทางแชต)
