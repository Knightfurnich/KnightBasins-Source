3 ข้อที่ต้องตัดสินก่อน (ผมเสนอค่าเริ่มต้นให้แล้ว)

1. "ระยะจากขอบ" อ้างอิงอะไร → เสนอ ขอบของชิ้นงาน (ไม่ใช่ขอบแผ่น/สี่เหลี่ยมย่อย) เพราะชิ้นงานหนึ่งอาจประกอบจากหลายสี่เหลี่ยม
2. การหมุน → เสนอ 90° เท่านั้น (0/90/180/270) และเก็บ offset แบบอิงมุมที่เลือก → สลับนอน/ตั้งแล้วระยะจากขอบคงเดิมอัตโนมัติ
3. ชิ้นงาน/ใบเสนอราคาเก่า → เสนอ migration อัตโนมัติ: บันทึกเก่า (ไม่มี anchor) แปลงเป็น anchor=top-left, offsetX=xMm, offsetY=yMm, rotation=0 และเติม pieceId จาก pieces[0] (พฤติกรรมเดิม) เพื่อไม่ให้ใบเสนอราคาเก่าขยับตำแหน่ง

ทั้ง 3 ข้อนี้เป็นตัวกำหนดตัวเลขที่ลูกค้าเห็น ถ้าคุณนพต้องการแบบอื่นบอกได้เลยครับ
