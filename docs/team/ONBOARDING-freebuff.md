## 3 · กฎเหล็ก 10 ข้อ

1. **ธุรกิจ:** Knight Furnich = หินสังเคราะห์ 3 รูปแบบขาย (แผ่นดิบ / งานผลิต+ติดตั้ง / อ่างชุดสำเร็จ) · B2C 70% / B2B 30%
2. **แอปจริง:** `https://knightbasins.com` · โค้ดอยู่ GitHub `Knightfurnich/KnightBasins-Source` (branch `main`)
3. **ห้ามแตะ production:** ห้าม `docker`/recreate เอง · ห้ามเขียน/ลบข้อมูล prod · ห้าม `DELETE` · ห้ามรัน migration เอง (ต้องผ่าน PR)
4. **ความลับ:** ห้ามพิมพ์คีย์/token/`.env`/รหัส ลงรายงาน แชท หรือล็อก
5. **ราคา/สี/ขนาด:** ห้ามคิดเลขเอง — ยึดข้อมูลจริงจาก `GET /api/catalog` (หน้าแอดมินเป็นแหล่งจริง) · รหัสสีคือตัวตนของสี (`KZ802` ≠ `KZ802N`)
6. **อ่างล้างหน้า:** รุ่นกลมต้องเป็น `Ø350x150` (ตัวอักษร Ø) ไม่ใช่ `D350x150` · `KF029/KF030` = **"เสาวางของตั้งพื้น" ไม่ใช่อ่าง** · รูน้ำล้น = **ตัวเลือกสั่งทำ** ไม่ใช่สเปกของรุ่น (ห้ามประกาศว่ามี/ไม่มีเป็นคุณสมบัติรุ่น)
7. **หลักฐานคือหัวใจ:** ทุกข้อสรุปต้องมี HTTP code / ผลรันจริง / ตัวเลข · **พิสูจน์สองทาง** (ถอดการแก้ → ต้องตก · คืน → ต้องผ่าน) · **ห้ามกุตัวเลข ห้ามคำรับรองลอย ๆ**
8. **ทำงานผ่านใบงานเท่านั้น:** `qa/job-NNN-*.md` → สาขาของตัวเอง → เปิด PR (**ห้าม push `main` ตรง · ห้าม merge เอง**)
9. **เวลา:** รายงานเป็นเวลาไทย (GMT+7) · เซิร์ฟเวอร์/DB ใช้ UTC
10. **มารยาท:** ไทย สุภาพ ติงานไม่ติคน · พลาดให้บอกทันทีพร้อมทางแก้ · รายงานตามจริง 100%

## 6 · โพรโทคอลตรวจงาน (ถ้าได้รับมอบหมายให้ตรวจงานคนอื่น)
1. รันเทสต์/ไทร์เอง ไม่เชื่อสรุปในรายงาน
2. ขับเส้นทางจริงบน production (ไม่ใช่อ่านโค้ดแล้วสรุป)
3. วัดจาก HTTP/DOM — ไม่ใช่กะด้วยตา
4. รายงาน pass/fail **ทีละข้อ** พร้อมหลักฐานดิบ
5. **ห้ามตอบ "ผ่าน" เพื่อให้รายงานดูเรียบร้อย**
6. ถ้างานสร้างของตัวเองชนกับงานตรวจ ⇒ **งานสร้างของตัวเองก่อน**
