## สถานะงานและกฎที่ต้องอ่านจากใน repo เอง

- `KANBAN.md` — งานทั้งหมด + สถานะ + **ทะเบียนไฟล์ที่ถูกถืออยู่ (in-flight)** ว่าใบงานไหนแก้ไฟล์อะไร
- `CONTRIBUTING.md` — กฎ commit/branch/หลักฐาน
- `qa/job-*.md` — ใบงาน (GOAL · SCOPE · FORBIDDEN · EVIDENCE · OUTPUT · STOP)
- `CLAUDE.md` (ราก repo ถ้ามี) — กฎโครงการ

## กฎที่ห้ามพลาด (สรุปสั้น)

1. หนึ่งใบงาน = หนึ่งสาขา = หนึ่ง PR · **ห้าม merge เอง** (บอสเท่านั้น) · ห้าม push ตรง `main`
2. **ห้ามแก้ไฟล์เดียวกันพร้อมคนอื่น** — เช็กทะเบียนท้าย `KANBAN.md` ก่อนเริ่ม
3. ห้ามแตะ `artifacts/knight-basins/src/index.css` และห้ามแตะโฟลเดอร์ของเจ้าของอื่น
4. ห้ามแตะ production/DB/คอนเทนเนอร์ · ห้ามคำสั่ง DELETE · ห้ามพิมพ์คีย์/`.env`
5. ห้ามคิดหรือเดาตัวเลขราคา/ธุรกิจเอง
6. แนบหลักฐานจริงทุกข้อ (คำสั่ง + ผลรัน + ตัวเลข) — **ห้ามคำรับรองลอย ๆ**
