---
name: Studio basin card sizing
description: The user-approved visual treatment for basin cards in the Studio shortlist.
---

The Studio basin shortlist should show three cards per row, with database basin images scaled to 115% inside each card image area.

**Why:** The user confirmed this balance makes the basin photos clearer and uses the card area better without cutting off the basin.

**How to apply:** Preserve the three-column grid and 115% image scale when adjusting the Studio shortlist; only revisit them if the user asks for a different visual treatment.
